# 운전자 설정·운전 환경·출발 준비 화면 — 2026-11-12

준비와 연습 화면의 진한 초록 강조색, 흰색 카드, 넉넉한 여백을 세 준비 화면에도 적용했다.

| 화면 | 변경 내용 |
|---|---|
| 운전자 설정 | 차량 정보와 저장·연결 설정을 왼쪽 카드로 분리했다. 오른쪽에는 키·체중, 운전 경험, 자신감, 안내 선호를 묶었다. 값과 선택한 항목을 강조하고 다음 단계 버튼을 아래에 고정했다. |
| 운전 환경 | 숫자만 있던 9단계 버튼에 항목 이름을 넣고 왼쪽 순서 목록으로 배치했다. 현재 단계의 설명과 자세·미러 그림은 오른쪽 카드에 표시한다. 확인 완료와 설명 다시 확인은 아래에 고정했다. 차량 수신 상세는 ‘차량 상태 보기’로 열 수 있다. |
| 출발 준비 | 7개 확인 항목을 ‘차량과 주변’, ‘운전자 확인’의 큰 체크 카드로 묶었다. 확인한 카드는 초록 배경과 체크 표시로 구분한다. 확인 개수를 위쪽에 표시하며, 모든 항목을 확인해야 연습 선택 버튼이 활성화된다. |

## 가독성과 화면 크기

- 제목 28~32sp, 주요 입력·확인 제목 20~24sp, 설명은 주로 18~22sp로 표시한다. 기존 앱의 1.2배 글자 확대 설정도 적용된다.
- 여러 줄 설명과 동의 문구는 내용에 맞춰 높이가 늘어난다. 큰 글씨나 좁은 화면에서는 카드 영역을 세로로 배치하며 긴 내용은 스크롤로 읽을 수 있다.
- 자세 그림의 설명은 18sp·16sp로 확대하고 줄바꿈을 지원한다. 글꼴 측정 결과를 재사용해 그림을 그릴 때 새 객체를 만들지 않는다.
- 준비가 덜 된 상태의 연습 버튼은 흐리게 표시해 사용할 수 없는 상태를 구분한다.

## 유지한 동작

차량에서 직접 조절·확인하는 기존 흐름, P·정차 조건, 안전벨트 연결값 검사, 자세 변경 시 미러·출발 확인 초기화, 저장·차량 연결 동의를 유지했다. 화면의 가상 시트 값은 실제 시트에 전송하지 않는다. 전기차 전용 문구를 조건부로 표시하는 기존 정책도 유지한다.

기획 대비 구현 등급은 화면 구성 변경만으로 올리지 않는다.

## 검증

- 최종 앱 빌드 성공, 단위 검사 359개·기기 검사 4개 통과. Lint 오류·경고 0개.
- 새 기기 검사 2개: 1,707dp 폭에서 글자 배율 1.2와 1.6, 1,100dp 폭에서 배율 1.2로 세 화면과 9개 설정 단계를 측정했다. 텍스트 잘림과 최소 터치 높이, 확인·해제, 자세 변경 후 재확인 조건을 검사했다. 별도 임시 설정을 사용했다.
- 기존 이용 흐름 검사 2개: 날씨·차량 기능·코스·준비·주행·복습·주차와 중단 후 복귀를 확인했다. 검사 후 기존 사용자 설정을 복원했다.
- 설치된 앱에서 운전자 설정, 시트 앞뒤, 오른쪽 미러, 출발 준비 화면을 직접 캡처해 배치와 줄바꿈을 확인했다. 출발 준비 캡처의 2개 체크는 화면 검사용이며 새 방문으로 초기화했다. 기록 저장 꺼짐·차량 연결 켜짐의 원래 설정을 다시 확인하고 운전자 설정 화면을 열어 두었다.

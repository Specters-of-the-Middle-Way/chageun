# 연습 선택·연습 기록 화면 및 준비 안내 정리

작업일: 2026-11-12 · 대상: 차근 Android 앱 / Pleos 2.1 에뮬레이터

## 요청별 반영 내용

| 요청 | 반영 내용 |
|---|---|
| 연습 선택 화면 정리 | 준비 상태를 위에 표시하고 ‘준비와 연습’, ‘차로 변경’, ‘주차’, ‘함께하는 연수’를 큰 카드 4개로 구성했다. |
| 연습 기록 화면 정리 | ‘나의 연습 현황’, ‘최근 남긴 소감’, ‘이번 연습 돌아보기’를 구분했다. 최근 소감은 최대 3개를 보여주고, 기록이 없을 때의 안내를 추가했다. |
| 글씨 가독성 | 제목·본문·선택 버튼을 키우고 여백과 줄바꿈을 적용했다. 주요 버튼은 아래에 고정하고, 좁은 화면은 세로 배치와 스크롤을 사용한다. |
| 출발 준비 체크 표시 | 체크한 항목 제목 뒤의 ‘✓ 확인’을 ‘✓’로 바꿨다. |
| 단계에 맞는 차량 값 | ‘차량 상태 보기’에서 현재 단계의 값만 토스트로 표시한다. 아래 대응표 참고. |
| 고정 안내 문장 | ‘시트 설정값을 보여드려요. 자세와 벨트 꼬임, 미러 시야는 직접 확인해 주세요.’를 화면에 유지했다. |
| 음성 완료 결과 제거 | 운전 환경·준비와 연습·함께하는 연수의 완료 결과 문구를 숨기고 빈 결과 영역도 접었다. Pleos 완료와 Android 대체 출력 완료에 모두 적용했다. |
| 메뉴바 문구 제거 | ‘P · 정차 중 사용’을 제거했다. 정차 조건 자체는 유지한다. |

## 차량 상태 토스트

| 운전 환경 단계 | 표시하는 정보 |
|---|---|
| 1. 시트 앞뒤 | 앞좌석 왼쪽 시트의 앞뒤 위치값과 제공된 범위 |
| 2. 시트 높이 | 앞좌석 왼쪽 시트의 높이 위치값과 제공된 범위 |
| 3. 등받이·허리 | 앞좌석 왼쪽 등받이 위치값과 제공된 범위. 별도 허리 지지 값은 제공하지 않는다. |
| 4. 헤드레스트 | 위치 정보가 제공되지 않는다는 안내 |
| 5. 핸들 위치 | 위치 정보가 제공되지 않는다는 안내 |
| 6~8. 룸미러·왼쪽 미러·오른쪽 미러 | 해당 미러 각도 정보가 제공되지 않는다는 안내 |
| 9. 안전벨트 | 체결 여부. 꼬임·밀착 상태는 직접 확인한다. |

위치값은 차량에서 읽은 원시 값과 범위를 표시하며 cm·각도로 임의 환산하지 않는다. 화면의 가상 조절값으로 대체하지 않으며, 차량 정보 연결이 꺼져 있거나 값이 없거나 오래되었으면 그 상태를 안내한다.

이 에뮬레이터에서는 기본 Android 텍스트 토스트가 화면에 보이지 않아, 앱 창 안에 표시하는 토스트로 보완했다. 약 4초 뒤 자동으로 사라지며 접근성 설정에 따라 시간을 늘릴 수 있다. 다시 누르면 새 내용으로 교체하고, 단계·화면 변경 또는 앱 비활성화 시 닫는다. 토스트는 터치와 화면 포커스를 가로채지 않는다.

음성 완료 신호는 내부 처리에 그대로 전달한다. 화면에서 완료 문구만 숨기므로 재생 완료에 따른 상태 갱신·다음 안내는 유지하며, 진행 중 상태와 오류 메시지도 유지한다.

## 검증

- `assembleDebug`, `testDebugUnitTest`, `lintDebug`, `assembleDebugAndroidTest` 통과.
- 단위 검사 **363개 통과**, Lint **오류 0개·경고 0개**. 단계별 차량 값, 연결 해제·누락·오래된 값과 음성 완료 문구 처리를 포함한다.
- 최종 APK 설치 후 에뮬레이터 계측 검사 **4개 통과**: `PreparationScreensDeviceTest` 2개, `WorkflowFlowTest` 2개.
- 화면 계측 검사는 연습 선택·기록을 포함한 준비 화면, 글자 배율 1.2/1.6, 기본 너비 1,707dp 및 좁은 너비 1,100dp에서 글자 잘림·말줄임·터치 크기를 검사한다.
- 기록 동의가 꺼진 상태에서는 소감을 저장하지 않고, 켠 상태에서는 저장 후 최근 소감에 표시하는 흐름을 격리된 테스트 저장소에서 검사했다. 기존 준비 확인·해제, 자세 변경 후 미러 재확인과 연습 진입 조건도 검사했다.
- 실제 화면에서 연습 선택 4개 카드, 기록 선택 상태, 출발 준비 체크 표시를 확인했다. 운전 환경의 실제 음성 재생 후 완료 문구가 사라지는 것도 확인했다. 외부 LLM 대화 전체 흐름을 이번 작업에서 재검사한 것은 아니다.
- 9단계에서 차량 상태 버튼을 직접 눌러 토스트 문구를 캡처·확인했다. 이 에뮬레이터의 시트 앞뒤·높이·등받이 수신값은 각각 `0`, 제공 범위는 `0~100`, 벨트는 ‘채워지지 않음’이었다. 4~8단계는 해당 항목 정보가 제공되지 않는다고 표시했다. 이는 에뮬레이터 수신값이며 자세 적합 여부를 판정한 것이 아니다.
- 토스트 자동 닫힘과 화면 이동 시 닫힘을 확인했다. 오른쪽 미러의 첫 캡처는 토스트를 놓쳐 해당 단계만 다시 눌러 확인했다. 화면 확인 후 최신 앱을 연습 기록 화면에 열어 두었다.
- 사용자 기록 저장 동의는 꺼짐, 차량 정보 연결은 켜짐으로 유지했다. 화면 확인 중 생성한 임시 준비 체크는 재실행으로 비웠고 소감을 저장하지 않았다.

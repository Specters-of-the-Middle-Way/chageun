앱 화면의 개발 프로토타입 소개·공모전 제약·향후 개발 계획·오래된 ‘이중 주차 의미 미확정’ 안내는 실제 이용 방법으로 교체했다. 위치 신뢰도 원본 값과 내부 경로 버전처럼 사용자의 판단에 도움이 되지 않는 표시도 정리했다. 연결 실패는 다시 연결하거나 권한을 확인하도록 안내한다.

가상 연습은 계속 가상이라고 표시한다. 시트·미러는 차량에서 직접 조절해야 하며, 연습 점수가 실제 운전 능력 평가를 뜻하지 않는다는 안내를 유지했다. 동의·개인정보 전송 범위와 데이터 출처를 나타내는 내부 식별자·저장 형식은 변경하지 않았다. 기본 내비의 지도·위치 문제를 해결된 것처럼 표시하지 않았다.

기존 화면 검사에서 찾던 문구를 새 표현에 맞췄고, 차량 연결 검사도 현재 날씨 교육 메뉴 경로를 사용하도록 갱신했다. 고정 음성 안내 카탈로그와 번들 음성은 이번 변경 대상이 아니다.

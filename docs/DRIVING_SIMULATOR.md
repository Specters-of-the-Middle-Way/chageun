# 운전자 시점 시뮬레이션 · v0.7

Pleos에서 실행되는 기존 Android 앱 안에 전방 도로·주변 차량·좌우 가상 미러와 직접 조작을 넣었습니다. 홈의 **도로를 보며 직접 연습 · 차로 변경**으로 들어갑니다. 객관식 답을 선택하는 대신 신호를 켜고, 미러를 확인하고, 핸들로 화면 속 차량을 이동시킨 뒤 회고합니다.

## 사용하는 순서

1. 실제 에뮬레이터 차량을 P·속도 0으로 둡니다. 앱의 정차 사용 제한은 그대로 적용합니다.
2. 왼쪽 차로 변경, 오른쪽 차로 변경, 옆 차를 기다린 뒤 변경 중 하나를 골라 시작합니다.
3. 화면 속 차량은 40 km/h로 출발합니다. 방향지시등 버튼으로 목표 방향의 신호를 켭니다.
4. 화면 좌우의 가상 미러를 보고 해당 방향의 **미러 보기**를 누릅니다. 버튼은 사용자의 확인 표시이며 시선 감지가 아닙니다.
5. 가상 차량이 가까우면 기다립니다. 핸들 슬라이더를 조금씩 움직여 목표 차로로 이동합니다. 슬라이더는 손을 떼어도 그 입력을 유지하므로 **핸들 중앙**으로 되돌립니다.
6. 목표 차로에서 핸들을 중앙으로 돌리고 방향지시등을 끄면 연습을 마칩니다. 방금 조작·코치의 개입을 회고하고 다시 연습할 수 있습니다.

가속·브레이크는 누르는 동안 동작합니다. 마우스 하나로도 신호·미러·핸들을 조작할 수 있도록 페달을 떼면 현재 가상 속도를 유지합니다. 실제 자동차의 관성·크루즈 동작을 재현한 모델은 아닙니다. 차량 겹침이나 도로 이탈 시 연습을 종료하고 명시적으로 다시 시작합니다.

## 상황과 반응

| 상황 | 구현한 반응 |
|---|---|
| 반대 방향 신호 | 목표 방향을 다시 알려주는 짧은 음성 |
| 신호·미러 확인 없이 횡방향 이동 | 빠진 조작을 알려주는 음성, 실제로 움직인 가상 위치는 유지 |
| 옆 차가 가까운 상태 | 미러의 강조와 대기 안내; 자동으로 차로를 바꾸지 않음 |
| 방향지시 중 급격한 속도 변화 | 기존 상황 감지 엔진으로 가속·감속 코칭 |
| 목표 차로에 도달 | 핸들 중앙·신호 끄기 안내 |
| 연습 완료·중단 | 조작 단계와 개입 근거를 최근 20회까지 로컬 저장 |
| 앱 이탈·실제 차량 주행 제한 | 가상 시간·페달·조향·음성 중단, 복귀 후 이어하기 필요 |

옆 차 대기 코스는 미러 확인 전까지 옆 차량이 학습자와 같은 가상 속도를 유지합니다. 올바른 미러 확인 뒤 옆 차가 앞으로 이동합니다. 초보자가 설명을 읽는 시간에 코스의 핵심 상황을 놓치지 않도록 만든 교육용 시나리오입니다.

## 구현 구조와 경계

- `DrivingSimulationSession`: Android·SDK에 의존하지 않는 순수 Kotlin 상태 모델. 차로 위치, 속도, 교통 차량, 조작 순서, 음성 개입을 계산합니다.
- `CockpitRoadView`: 같은 스냅샷으로 전방 원근 도로·주변 차량·좌우 미러·가상 계기판을 그립니다. 자체 차량 상태나 SDK 구독이 없습니다.
- `DrivingSimulatorView`: 화면 조작, 타이머, 음성 요청, 일시 정지, 회고 저장을 담당합니다.
- `MainActivity`: 기존 `ParkedGate`와 앱 수명주기를 연결합니다. 실제 차량 신호 변경이나 음성 상태 갱신 때문에 조작 화면을 다시 붙이지 않습니다.

이 화면의 차선·주변 차량은 작성된 가상 데이터입니다. 실제 카메라 영상이나 ADAS 감지 결과가 아니며, 실제 도로에서 차로 변경해도 되는지 판단하거나 차량을 조종하지 않습니다. 도로의 강조 표시는 코스의 목표 위치이며 안전 판정이 아닙니다. 실차 핸들 각도·회전 수·제동거리로 환산해서 사용할 수 없습니다.

공식 Pleos 문서는 플랫폼의 `CarUxRestrictions` 상태에 따른 기능 제한 적용을 요구합니다. 이 프로토타입도 기존 정차 사용 제한을 유지합니다. [Pleos 주행 제한 개발 가이드](https://document.pleos.ai/en/docs/pleos-only/vehicle-app-developer-guide/driving-restriction-development-guide) (확인: 2026-11-09)

실주행 음성 튜터로 확장하려면 차종별 읽기 권한과 신호 가용성, 주변 인식 데이터, 주행 중 사용 승인, 교육 전문가와의 코칭 검증이 별도로 필요합니다. 이번 버전의 결과는 정차 중 가상 연습의 작동 검증입니다.

## 검증

단위 테스트는 방향별 완료, 선행 조작 누락, 옆 차량 대기, 속도 변화, 충돌·이탈, 잘못된 입력과 일시 정지 경계를 다룹니다. 에뮬레이터 통합 검증은 실제 화면 조작·번들 음성 재생 시작·저장과 재실행·주행 제한·실제 차량 상태 불변을 확인합니다. 최종 실행 결과는 `DRIVING_SIMULATOR_VALIDATION.md`에 기록합니다.

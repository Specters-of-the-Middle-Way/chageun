# v0.8 · 플로우차트 반영과 IONIQ 3 데모

기준일: 2026-11-09. 사용자 제공 **드라이브스텝 상세 플로우차트 11쪽**과 추가 요청을 함께 반영한 개발 참고 문서입니다. 문서의 실차 서비스 목표와 이번 정차용 가상 시뮬레이션을 구분합니다. 최종 검증은 [v0.8 검증 기록](V08_VALIDATION.md)에 정리합니다.

## 1. 흐름을 어떻게 반영하는가

```text
운전자·차량 확인 → 운전 환경 9항목 → 이번 출발 전 7항목
                                        ↓
                가상 주행 / 가상 주차 / 정차 교육
                                        ↓
                       조작 회고·자기평가 → 다음 연습
```

| 원본 페이지 | 이번 변경의 반영 범위 | 남겨 둔 범위 |
|---|---|---|
| 1 전체 지도 | 준비·연습 선택·복습을 하나의 진입 흐름으로 구성 | 실차 주행과 자동 연계하는 전체 서비스 |
| 2 첫 실행·프로필 | 데모 체격, 운전 경험·자신감·안내 선호 저장, 기록·차량 연결 선택 | 신체 센서 자동 측정·실제 숙련도 자동 판정 |
| 3 시트·핸들 | 시트 앞뒤·높이·등받이·헤드레스트·핸들의 단계별 수동 확인 | 검증된 실차 시트 mm·각도 산출과 자동 이동 |
| 4 미러·안전벨트 | 룸미러·좌우 미러·벨트 확인, 자세 변경 시 미러 확인 해제 | 미러의 적정 시야·벨트의 올바른 착용 자동 판정 |
| 5 출발 전 확인 | 벨트·문/경고·발밑/짐·시야·조작·잔량·컨디션의 수동 확인 | 미연결 차량 신호를 자동 확인된 사실처럼 표시하지 않음 |
| 6 오늘의 연습 | 운전자 시점 주행, 주차 시뮬레이션, 정차 교육 진입 | 실제 목적지·내비 경로 연결 |
| 7 주행 | 기존 가상 주행과 고정 문구 코치 유지 | 실제 주행 중 교육 승인·내비/ADAS 우선순위 통합 |
| 8 주차 | **후진·평행 가상 주차 추가**, 직접 기어·핸들·페달 조작과 회고 | 실차 장애물 인식·실시간 조향 지시·실차 주차 성공 판정 |
| 9 복습 | 저장된 가상 조작과 사용자 응답의 출처를 분리 | 실제 동일 경로 비교·정체/날씨 조건 보정 |
| 10 숙련도 | 학습 완료·자신감·실차 숙련도 미평가를 구분 | 검증된 항목별 0~10 숙련도 갱신 |
| 11 재방문·중단 | 프로필 재사용, 이번 출발 전 확인 초기화, 바뀐 자세·미러 재확인 | 차량 변경을 센서로 자동 판별하거나 다른 차량에 값을 자동 적용 |

사용자가 ‘확인하지 못함’을 선택한 항목은 완료로 바꾸지 않습니다. 시트·핸들 가상 조절값을 바꾸면 관련 확인과 미러 확인을 해제합니다. 저장된 준비 완료를 다음 방문의 현재 차량 상태로 재사용하지 않습니다. 앱의 연습 진입 조건과 실제 차량 출발 허가는 별개입니다.

## 2. 데모 차량과 공식 제원

데모 기준은 **유럽형 IONIQ 3 기본 차체, N Line 제외**입니다. 특정 국내 판매 트림의 장비·제어 권한까지 확인했다는 뜻은 아닙니다.

| 항목 | 값 | 이번 사용 |
|---|---|---|
| 전장 | 4,155mm | 가상 차량 차체 길이 |
| 전폭 | 1,800mm | 가상 차량 차체 폭, 미러 제외 |
| 전고 | 1,505mm | 모델의 차량 메타데이터 |
| 축거 | 2,680mm | 가상 자전거 모델의 앞뒤 차축 거리 |
| 미러 포함 폭 | 2,100mm | 참고 정보. 현 충돌 모델에는 포함하지 않음 |
| 회전원 지름 | 10.4m, 16/17인치 휠 기준 | 공식 참고치. 모델의 후륜축 회전반경으로 직접 변환하지 않음 |
| 좌우 끝 조향 회전 수 | 2.5회, 16/17인치 휠 기준 | 공식 참고치. 시뮬레이터 슬라이더와 실차 핸들 회전 수를 동일시하지 않음 |

N Line은 유럽 기술표에서 전장 4,170mm·전고 1,510mm로 구분됩니다. 휠·트림별 값이 다를 수 있으므로 하나의 숫자를 모든 IONIQ 3에 적용하지 않습니다.

- [현대 유럽 IONIQ 3 기술 제원](https://www.hyundai.com/eu/en/models/ioniq-3/technical-data-downloads.html)
- [현대 UK IONIQ 3 제원·장비 발표, 2026년 8월](https://www.hyundai.news/uk/articles/press-releases/ioniq-3-uk-pricing-august-2026.html)

## 3. 체격과 시트 보정값의 의미

데모 인물은 **키 180cm·몸무게 78kg(요청 범위 75~80kg)·동양인 남성**으로 설명합니다. 성별·인종은 요청한 데모 인물의 설명이며, 시트 보정 계수로 사용하지 않습니다. 키와 체중만으로 다리 길이·앉은키·팔 길이·관절 가동 범위나 적절한 시트 위치를 확정할 수 없습니다.

시트 앞뒤·높이·등받이·핸들 위치의 기본값 **50**은 화면을 조작하기 위한 중립 시작값입니다. 입력 범위는 0~100이며, 실차의 mm·도·전동 모터 위치 또는 SDK 좌표와 대응하지 않습니다. ‘AI가 180cm에 맞춰 계산한 최적 시트값’으로 표시하지 않습니다.

초기 흐름은 조절 위치와 확인 사항을 보고 사용자가 직접 조정·확인하는 방식입니다. 실차 자동 보정을 개발하려면 해당 트림의 시트 가동 범위·좌표 정의·제어 권한, 신체 치수와 자세 평가 기준, 전문가 검증이 필요합니다. 공개 자료에서 확보하지 못한 시트 좌표·H-point·조절 각도 범위를 추정값으로 채우지 않습니다.

안내 선호는 프로필 기록이며 현재 음성 문구는 공통 고정 문구입니다. 선호별 문구 길이·발화 빈도 자동 조절은 추후 연결할 기능입니다.

## 4. 새 주차 시뮬레이션

실제 차량은 플랫폼이 정차 사용을 허용한 상태를 유지하며, 화면 안에서만 움직입니다. 코스는 두 가지입니다.

| 코스 | 가상 연습 |
|---|---|
| 후진 주차 | 브레이크 → R → 저속 후진 → 멈춤 → P → 사용자 완료. 기본 코스는 주차 공간과 정렬된 시작 위치 |
| 평행 주차 | 두 번의 반대 방향 조향을 포함해 직접 후진하며 공간에 맞추는 코스. 자동 주차·자동 위치 보정 없음 |

속도와 기어, 조향은 연속 가상 모델로 연결합니다. P에서 가속해도 움직이지 않으며, 기어 변경은 정지와 브레이크 조건을 요구합니다. 가속 페달을 놓으면 가상 감속으로 멈추고, 브레이크가 가속보다 우선합니다. 장애물과 차체가 겹치거나 연습장을 벗어나면 해당 연습을 중단합니다.

### 물리 모델의 확인된 값과 가정

- 공식 차체 길이·폭·축거를 사용합니다. 충돌·주차 구역 검사는 **미러를 제외한 차체 사각형**에 대한 검사입니다.
- 전륜 조향 최대 **32°**, 앞뒤 오버행의 동일 분배, 가상 최대 속도 **5km/h**, 가속·감속 계수는 교육용 가정입니다. 실차 교정값이 아닙니다.
- 자전거 모델의 후륜축 위치를 적분하고, 가정한 차체 중심 오프셋을 적용합니다. 타이어 미끄러짐·서스펜션·실차 조향비·모터 지연은 재현하지 않습니다.
- 예상 궤적은 현재 가상 조작을 유지했을 때의 수학적 표시입니다. 카메라·주차 센서가 읽은 실측 궤적이 아닙니다.
- 가상 구역에 차체 네 모서리가 들어가고 방향 오차가 모델 허용치 8° 이내여도 자동 완료하지 않습니다. 사용자가 정지·P 상태에서 완료를 눌러야 합니다.

**가상 주차 구역 판정은 원본 플로우차트의 ‘실차 주차 성공 자동 판정’과 다릅니다.** 작성된 화면 속 좌표의 적합성을 확인하는 기능이며 실제 차가 주차선 안에 있는지, 주변이 안전한지 또는 운전 숙련도가 향상됐는지를 증명하지 않습니다.

### 구현 위치

- `parking/ParkingSimulationSession.kt`: 순수 Kotlin 상태·기하·기어/페달·코칭 모델.
- `parking/ParkingSimulatorView.kt`, `parking/ParkingSceneView.kt`: 조작 UI와 가상 주차장 렌더링.
- `docs/parking-simulation-voice-cues.json`: 신규 고정 한국어 문구 16개.
- `journey/JourneyState.kt`: 프로필·수동 확인·재방문·가상 보정값 상태.

위 Kotlin 경로의 앞에는 `app/src/main/java/kr/drivestep/tutor/`가 붙습니다.

## 5. 플레오스 UI와 에셋

공식 Pleos 디자인 가이드와 실제로 제공되는 Android 위젯 SDK는 구분합니다. 공개 디자인 가이드·Figma 에셋이 존재한다는 사실만으로 완성된 Android UI 라이브러리가 앱에 연결된 것은 아닙니다.

이번 앱의 레이아웃·아이콘·Canvas 차량 그래픽은 직접 구현합니다. 공식 Typography 가이드에서 소개하는 **Asta Sans**를 원본 글꼴로 포함하고, **SIL Open Font License 1.1** 고지와 출처를 `third_party/asta-sans/`에 보관합니다. 독자 구현한 화면을 공식 Pleos 위젯 또는 Hyundai 차량 UI 에셋이라고 표시하지 않습니다.

- [Pleos 디자인 가이드](https://document.pleos.ai/docs/connect/guide/docs-design/Introduction/intro)
- [Pleos Typography](https://document.pleos.ai/docs/connect/guide/docs-design/foundations/typography)

## 6. 검증 상태와 다음 확인

전체 JVM 단위 테스트 **205개**(기존 148 + 주차 33 + 준비 흐름 24), Debug/Release 빌드, lint 오류 0을 확인했습니다. 신규 고정 음성 16개를 추가해 전체 194개를 포함합니다.

에뮬레이터에서 두 주차 코스의 직접 조작 완료, 잘못된 기어 조작 수정 음성, 자기평가·동의 기반 기록, 재방문 시 출발 확인 초기화, 실제 주행 제한, 화면 밖으로 이동할 때 멈춤을 확인했습니다. 세부 실행 이력과 한계는 [검증 기록](V08_VALIDATION.md)을 확인하세요.

남은 확인은 실차 시트·미러·조향 좌표와 제어 권한, 실제 주차 센서·영상 API, 차량별 화면·입력 지원, 교육 전문가의 문구·학습 효과 검증입니다. 안내 선호별 음성 조정, 실제 내비 연동과 동일 경로 비교, 검증된 운전 숙련도 갱신은 이번 구현 범위에 포함하지 않았습니다.

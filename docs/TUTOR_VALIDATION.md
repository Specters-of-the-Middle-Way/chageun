# v0.2 · 다정한 음성 안내와 상황별 튜터

2026-11-08 · 앱 버전 0.2.0 / versionCode 2. Pleos Connect v2.1.0 ARM64, Android 14 에뮬레이터에서 확인했습니다.

## 구현한 사용자 흐름

**방향지시등:** 조작법 설명 → 정차 상태의 상황 제시 → 실제 SDK 변경 수신 → 문구와 음성 피드백 → 기존 완료 기록 저장·복습.

| 상황 | 안내 예시 |
|---|---|
| 처음 시작 | “정차한 채, 왼쪽으로 출발할 상황을 연습해요.” |
| 왼쪽을 요청했는데 오른쪽을 켬 | “지금은 오른쪽 신호가 켜져 있어요. 괜찮아요. 방향지시등을 모두 끈 뒤 왼쪽부터 다시 해 봐요.” |
| 왼쪽을 제대로 켬 | “좋아요. 왼쪽 신호가 켜진 것을 확인했어요.” |
| 잘못된 조작 뒤 모두 끔 | 끈 사실을 확인하고 필요한 방향을 다시 안내 |
| 전체 완료 | 켜고 끄는 연습 완료를 칭찬하고 복습으로 연결 |

칭찬은 관측된 조작에 한정합니다. 안전한 진입, 거울 확인, 양보 판단을 완료했다고 말하지 않습니다. 문구 선택은 고정 규칙이며 LLM 판단이 아닙니다.

**후진주차:** 정차한 채 다섯 상황을 설명과 질문으로 익힙니다. 주변 확인 / 완전히 멈춘 뒤 후진 준비 / 후진 중 관찰 / 정렬이 불확실할 때 멈춤 / 주차 마무리입니다. 틀린 답에는 이유와 재안내, 맞는 답에는 칭찬을 제공합니다. 맞는 답을 확인해야 다음 상황으로 넘어갈 수 있습니다. 차 그림은 설명용이며 실제 경로를 그리지 않습니다.

주차 이해 확인은 현재 학습 과정의 메모리 상태입니다. 홈으로 나가거나 앱 프로세스가 종료되면 다시 시작합니다. 방향지시등 실습의 SQLite 기록과 구분하며, 주차 성공·운전 숙련도 점수로 저장하지 않습니다.

## 음성과 플랫폼 처리

- 한국어 Android TTS의 초기화·언어 지원을 확인합니다. 사용할 수 없거나 재생이 실패하면 같은 문구의 앱 내 WAV를 사용합니다.
- 이 에뮬레이터에는 TTS 서비스가 조회되지만 실제 앱 실행에서는 기본 WAV로 재생됐습니다. **TTS 경로의 실차 성공을 검증한 것은 아닙니다.**
- 기본 한국어 음성 31개, 최장 13.376초. 각 파일의 실제 PCM 데이터·길이·해시를 확인했습니다. `voice-assets.json`에 목록이 있습니다.
- 음성 안내 스위치, 명시적 다시 듣기, 새 안내로 교체, 중복 이벤트 재생 방지를 구현했습니다.
- Android 오디오 포커스를 요청하고, 거절되거나 상실하면 화면 안내를 사용합니다. 다른 앱으로 전환되거나 주행 제한이 생기면 재생을 멈추고, 오래된 안내를 자동 재개하지 않습니다.
- TTS와 WAV의 시작에 200ms 무음을 적용했습니다. [Pleos의 시작 무음 안내](https://document.pleos.ai/en/docs/pleos-only/vehicle-app-developer-guide/voice-guidance-preroll-silence-guide)에 따른 값이며 실제 차량의 첫음절·음량은 별도 확인해야 합니다.
- 기본 WAV는 로컬 macOS Yuna 음성으로 생성한 개발 시연 자산입니다. 공개 제출·배포용 음원과 사용 권한은 별도로 확정해야 합니다.

## 검증 기록

전체 단위 테스트 **29개**: 기존 실습 상태 13개 + 음성 문구 선택 11개 + 주차 학습 상태 5개. APK 빌드와 Android lint의 오류 없는 완료를 확인했습니다. 동적 음성 자원·프로그램 방식 뷰 등 일부 lint 경고는 남아 있습니다.

에뮬레이터 연결 시험은 `scripts/verify-tutor.py`로 재현하며, 최종 실행 로그는 `test-results/tutor-smoke.txt`에 보관합니다. 앱의 재생 시작 로그뿐 아니라 Android AudioService의 해당 앱 재생 상태를 읽어 음성 활성화와 중지를 확인합니다. 소리가 실제 사람에게 얼마나 자연스럽고 편안한지는 사용자 청취 평가가 필요합니다.

검증 항목: 조작법 음성 / 실제 SDK 오조작과 정상 조작의 서로 다른 음성 / 실습 완료 저장 / 주차 오답·정답 피드백 / 정답 전 다음 단계 차단 / 음소거 / 다시 듣기 / 주차 다섯 단계 완료 / 화면 이탈 및 주행 제한 시 음성 중지.

Pleos의 HOME 키는 앱을 포함한 화면을 유지할 수 있어, 화면 이탈 시험은 실제 Settings 앱 전환으로 수행합니다. 테스트 스크립트는 에뮬레이터에서만 실행되며 차량 제어 코드는 제품 앱에 들어 있지 않습니다.

## 조작 설명의 근거와 한계

- 방향지시등의 위·아래 조작은 [현대자동차 레버형 조작 설명](https://ownersmanual.hyundai.com/full_webhelp/ME/2025/ko_KR/id23C697005HS.html)을 참고한 예시입니다. 앱은 차종을 자동 식별하지 않으며 다른 조작 방식에 그대로 적용한다고 주장하지 않습니다.
- 정지 후 변속, 브레이크를 밟은 상태의 조작, 계기판 변속 표시와 주차 브레이크 확인은 [현대자동차 변속기 설명](https://ownersmanual.hyundai.com/full_webhelp/US4/2026/ko_KR/id_sws_fbv_rgc.html)을 참고했습니다. 차종별 변속 조작은 해당 설명서가 우선입니다.
- 센서·화면만으로 모든 장애물을 확인할 수 없다는 설명은 [현대자동차 주차 보조 제한 사항](https://ownersmanual.hyundai.com/full_webhelp/ne1n/2025/ko_kr/id6f8c73b8aefa.html)을 참고했습니다.

이번 구현은 정차 중 교육입니다. 실제 후진 중 지시, 핸들을 몇 바퀴 돌릴지 판단, 주차선·장애물 거리 인식, 자동 주차, 연수 대체 효과는 구현·검증하지 않았습니다. 실차 음성 출력과 차량 경고·내비·전화의 우선순위도 별도 확인이 필요합니다.

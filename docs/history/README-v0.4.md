# 드라이브스텝 v0.4 · 성장형 운전 튜터

장롱면허·초보 운전자가 **내 자리 맞추기 → 기본 조작 → 교통 규칙 → 복잡한 상황 판단 → 복습**으로 이어가는 정차용 시뮬레이션 프로토타입입니다. 기존 방향지시등·기어·조향 SDK 실습도 유지했습니다.

## 가장 쉽게 켜는 방법

이 컴퓨터에서 `scripts/launch-tutor.command`를 더블클릭합니다. 준비된 Pleos 에뮬레이터를 찾거나 켜고, 앱을 설치·실행합니다. 다른 에뮬레이터나 기존 연습 기록을 지우지 않습니다.

직접 실행하려면 프로젝트 터미널에서:

```bash
./scripts/run-emulator.sh
```

부팅 후 다른 터미널에서:

```bash
./scripts/install.sh
```

이미 에뮬레이터가 켜져 있으면 첫 명령을 반복하지 않습니다. 빌드하려면 `./scripts/build.sh`를 사용합니다.

## 이번 버전에서 사용하는 순서

1. **처음 시작 · 내 자리 맞추기**: 키 범위와 몸의 비율을 선택합니다. 체격별 확인 항목이 바뀝니다.
2. **기본 세팅 6단계**: 시트 거리, 높이, 핸들, 머리 받침·벨트, 사이드미러, 백미러를 움직이는 도식과 음성으로 확인합니다. 실제 시트·미러의 자동 조절이나 센서 확인은 하지 않습니다.
3. **연습 지도**: 9개 과정·27개 상황을 연습합니다. 앞 장을 마치면 다음 장이 열립니다.
**고급 상황을 바로 보고 싶다면** ‘모든 상황 미리보기 · 점수 미반영’을 누르세요. 기본 세팅·앞 과정 완료와 관계없이 골목·언덕 등을 바로 체험하며, 이 모드에서는 기록과 포인트가 바뀌지 않습니다.

4. **상황 선택**: 선택에 따라 가상 차량이 정지·차로 유지·양보·차로 복귀하는 모습을 봅니다. 반대 선택에는 이유를 설명하고 다시 연습합니다.
5. **성장 기록 · 연습 순위**: 항목별 결과와 최근 연습을 봅니다. 과정별 최고 점수만 누적합니다. 가상 참가자가 포함된 예시 순위이며 실제 사용자 서버에 연결되지 않습니다.
6. **실제 SDK 조작 실습**: 기존 방향지시등과 P·정지 조향 신호 확인 화면으로 이동합니다. 해당 화면의 홈에서 ‘성장 튜터로 돌아가기’를 누르면 돌아옵니다.

## 연습 과정

| 장 | 과정 | 배우는 핵심 |
|---|---|---|
| 1 | 내 차와 친해지기 | 자세·미러·벨트 직접 확인 |
| 1 | 차분하게 출발하기 | 주변·사각 확인 → 방향지시 → 양보 |
| 2 | 실선 앞에서 판단하기 | 진로변경제한선, 길을 놓쳤을 때 재탐색 |
| 2 | 우회전 신호 읽기 | 차량 적색, 보행자, 우회전 전용 신호 구분 |
| 2 | 추월 후 돌아오기 | 고속도로 주행차로 복귀, 정체 예외 |
| 3 | 골목에서 마주쳤을 때 | 정지 → 후방·이동 구간 확인 → 가상 양보공간 |
| 3 | 좁은 언덕에서 양보하기 | 좁은 비탈길의 양보 원칙과 실제 공간 확인 |
| 3 | 터널의 공기와 시야 | 편의 기능과 법규 구분, 시야와 차간거리 |
| 3 | 고마움을 안전하게 표현하기 | 예측 가능한 합류, 실수 후 급조작 줄이기 |

골목·언덕·출발 과정에서는 **가상 핸들 슬라이더**로 그림 속 조향 방향을 바꿔볼 수 있습니다. 실제 핸들 각도·회전 수·통과 가능 공간을 계산하는 물리 시뮬레이터는 아닙니다. 감사 비상등 버튼은 화면 속 두 번 깜빡임 시연이며 실제 비상등을 켜지 않고 점수에도 반영하지 않습니다.

## 점수와 기록

- 각 과정의 완료 확인 단계 비율에서 고유 오답당 10점을 빼고 0~100점으로 표시합니다.
- 같은 오답 버튼을 반복해 눌러도 추가 감점하지 않습니다. 정답 후 중복 입력도 무효입니다.
- 완료된 과정만 기록합니다. 미완료 상황은 재시작할 때 처음부터 시작합니다.
- 학습 포인트는 과정별 최고 점수의 합입니다. 100점 과정 재연습으로 무한 포인트를 얻지 못합니다.
- 항목은 출발 준비·기본 조작·교통 규칙·상황 판단·안전·배려로 나뉩니다. 미연습 항목은 ‘미연습’입니다.
- 키 범위·몸 비율·직접 확인·학습 점수는 앱 내부에 저장합니다. 실제 SDK 기록과 별도입니다.
- 점수는 선택 기반 가상 학습 성취도이며 실제 운전 능력이나 도로 연수 수료를 인증하지 않습니다.

## 구현 범위와 이후 작업

현재 완료: 네이티브 Android 화면, 움직이는 2D 도식, 선택에 따른 가상 행동, 한국어 음성, 과정 해제, 재시도, 로컬 기록, 최고 점수 반영, 예시 순위, 기존 SDK 메뉴 연결.

이후 검증: 실제 차종의 좌석·미러 신호 접근, 실제 주변 인식과 기하 모델, 실도로 코칭의 허용 범위, 교육 전문가 검토와 사용자 학습 효과. 카메라로 현장을 인식하거나 ‘지금 몇 도 돌리면 안전’이라고 지시하는 기능은 없습니다. 추가 영상은 현재 도식 애니메이션으로 시연하며 실사 영상 콘텐츠는 포함하지 않았습니다.

사용자의 ‘터미널 창문’ 예시는 **터널 진입**으로 해석했습니다. 창문 닫기를 교통법규 위반 항목으로 채점하지 않습니다. 우회전·고속도로·비탈길 등의 근거는 [콘텐츠 근거](docs/GROWTH_SOURCES.md)에 정리했습니다.

## 환경과 검증

Pleos 전용 에뮬레이터 2.1.0 / Android 14, Vehicle SDK 2.3.2, JDK17, compileSdk35, targetSdk34, Gradle8.10.2, AGP8.8.2. 이 Mac의 SDK·AVD는 `.tooling`에 준비되어 있고 소스 ZIP에는 포함되지 않습니다. 다른 컴퓨터에서는 [Pleos 공식 설치 안내](https://document.pleos.ai/en/docs/connect/guide/getting-started/application-development/setup-connect-sdk-emulator)를 따릅니다.

```bash
./scripts/build.sh :app:assembleRelease
./scripts/install.sh
python3 -u scripts/verify-growth.py
```

통합 시험은 에뮬레이터에 학습 기록을 추가합니다. 기존 데이터를 지우지 않습니다. [v0.4 검증 결과](docs/GROWTH_VALIDATION.md), [기존 SDK 조향 검증](docs/STEERING_VALIDATION.md), [이전 사용 설명서](docs/history/README-v0.3.md)를 참고하세요.

앱에는 기본 한국어 음성 134개를 포함했습니다. 한국어 TTS를 사용할 수 있으면 사용하고, 실패하면 기본 WAV로 안내합니다. 새 음성 89개는 성장 과정과 자세 가이드용입니다. 이는 상황별 고정 안내로, LLM이 현장 운전을 판단하는 기능이 아닙니다.

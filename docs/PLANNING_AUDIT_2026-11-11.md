## 7-1. 후속 날씨 버튼·가독성 변경 및 기본 내비 진단

- **현재 위치 날씨 조회:** 지역 선택 6개와 지역별 조회 버튼을 제거하고 현재 위치 조회 버튼 하나로 통일했다. 기존 동의·권한 확인과 위치 미확인 시 복정동 대체는 유지했다.
- **읽기 편한 글씨:** 차근 앱의 시스템 글자 배율에 1.2배를 적용하고, 그림 안의 설명도 같은 SP 배율을 사용한다. 보조 설명 색상 대비를 높였다. 시스템 내비 등 다른 앱의 배율은 바꾸지 않았다.
- **최종 검사:** 22:01 KST APK 설치, JVM **355개 통과**, lint **오류·경고 0**, 기획·날씨·복습·도로 교육 계측 **12개 재실행·통과**. 이전 워크플로 6개는 이번 글씨 변경 뒤 다시 실행하지 않았다.

## 7-2. 앱 실행 시 자동 날씨·TTS 음량·내비 추가 진단

- **자동 안내:** 앱의 새 전경 실행에서 현재 위치 날씨를 한 번 조회하고 홈의 ‘출발 전 날씨’와 기기 내 TTS로 조언한다. 조회 버튼이나 맑음/비/눈 예제를 누를 필요가 없다. 위치 실패 시 복정동 기준임을 명시한다. 실패/화면 이탈 뒤에는 상세 화면에서 다시 조회할 수 있다.
- **상세 연결과 설정:** 홈의 결과를 상세 화면에서도 재조회 없이 표시한다. 상세 진입으로 TTS를 반복하지 않는다. 자동 조회·자동 읽기·전송 동의는 각각 저장하며, 좌표와 날씨 응답은 디스크에 저장하지 않는다. 사용자의 자동 안내 요청에 맞춰 세 설정의 기본값은 켜짐이다. 전역 음소거와 화면 비활성화를 우선한다.
- **교육 분리:** 비·눈·안개·저온을 눌러 보는 기존 예제는 ‘날씨별 대응 교육 보기’ 아래 가상 상황으로 옮겼다. 오늘 날씨를 알려 주는 흐름과 구분한다.
- **TTS 음량:** 에뮬레이터의 안내 오디오 그룹을 **20/45 → 30/45**로 변경했다. 미디어 음량은 기존 20으로 유지했다. 재부팅 후 30 유지 확인. 25초 Windows 출력 녹음 RMS가 0.01075 → 0.03351로 약 **9.9dB 증가**, 최종 peak 0.28024, clipping 0이었다. 이 설정은 현재 AVD에 적용된 것이며 모든 실차의 볼륨을 강제하는 코드가 아니다.
- **간헐적 깨짐:** 자동 날씨 발화의 TTS 초기화·시작·완료는 정상이고, 측정 구간에는 디지털 클리핑이나 녹음 중단 경고가 없었다. 깨짐을 이번 구간에서 특정하지 못해 에뮬레이터 탓으로 확정하지 않는다. AudioFlinger의 누적 underrun만으로 원인을 단정하지 않았고 합성기/오디오 버퍼를 임의로 변경하지 않았다.
- **기본 내비 미해결:** 자동차 환경에서 기본 좌표를 반환하는 위치 코드 분기와 NMEA 체크섬 오류를 확인했다. 최신 공식 이미지도 동일 revision 2다. 정상 지도·경로 안내 복구는 미확인으로 유지한다. [추가 진단과 필요한 공급 측 수정](NATIVE_NAV_DIAGNOSIS_2026-11-11.md)에 기록했다.
- **최종 검증:** 22:49 KST APK 빌드·재설치 성공, JVM **359개 통과**, lint **오류·경고 0**. 에뮬레이터 **20개(기획·날씨·도로 교육 14 + 기존 흐름·복구·아이콘 6) 재실행·통과**. 자동 조회/꺼짐 저장과 상세 화면 결과 전달·중복 발화 없음도 확인했다. 검사 전 사용자 설정과 기록을 복원했다.

## 7-3. 지도 원인 확인·에뮬레이터 GPS 입력 보정

- **흰 지도 원인 확인:** 배포 기본 내비의 coral 분기가 도로 없는 `connect_empty` 스타일을 선택한다. 공개 응답을 비교하면 빈 스타일은 소스 1개·레이어 4개, 일반 `connect_v2`는 소스 17개·레이어 263개다. 앞선 7-1·7-2의 원인 미확정 상태를 갱신한다.
- **NMEA 보정 완료:** `-no-passive-gps`와 정상 체크섬 입력 도구로 오류를 제거했다. 정상 문장 25쌍은 오류 0건, 오류 문장 1개 대조 검사는 오류 1건, 최종 추가 30초 검사는 오류 0건이었다. [재실행 도구](../scripts/start-pleos-windows.ps1)를 추가했다.
- **위치 검증 범위:** Android GPS/FusedLocation은 복정동 시험 위치를 받고 차근 자동 날씨는 6.1°C를 표시했다. 이 모드는 고정된 에뮬레이터 시험 위치이며 실제 주행이나 PC GPS 수신이 아니다.
- **기본 내비 미해결:** 기본 내비는 여전히 흰 지도와 시흥동 마커를 표시한다. 자동차 환경에서 기본 좌표로 치환하는 코드 경로도 남아 있다. 개발 메뉴 비밀번호는 제공받은 것이 없으며, 공급사 서명된 수정 빌드나 공식 설정 지원이 필요하다. 정상 지도·위치 이동·경로 안내를 통과로 표시하지 않는다.
- **점검 집계 유지:** R09는 부분 구현이다. 이번 작업은 실행 도구와 진단 문서를 변경했으며 차근 APK를 변경하거나 앞선 359개·20개 앱 검사를 다시 실행하지 않았다.

상세 근거·현재 제한·복원 방법은 [기본 내비 진단](NATIVE_NAV_DIAGNOSIS_2026-11-11.md)에 정리했다.

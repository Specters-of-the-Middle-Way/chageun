# 함께하는 연수 — 대화부터 조작 복습까지

차근 v0.10은 운전자가 짧게 요청하면 준비 순서를 안내하고, 실제 또는 가상 조작을 기록해 복습과 다음 연습으로 연결합니다. 현재 실행 형태는 **정차 중 에뮬레이터 검증용 프로토타입**입니다. 기존 주행 제한을 해제하지 않았으며, 실도로 주행 중 음성 코치 사용 승인·실차 검증은 별도입니다.

## 실행

1. README의 설치 절차대로 Pleos 에뮬레이터에서 앱을 실행합니다. 실제 에뮬레이터 차량은 P·속도 0으로 둡니다.
2. 상단 **함께하는 연수**를 누릅니다. 연습 선택이나 교육 메뉴에서도 진입할 수 있습니다.
3. 차로 변경 준비, 회전 미리 준비, 출발·정지 돌아보기 중 오늘의 항목을 선택합니다.
4. **함께 시작하기**로 연수에 들어가면 처음 안내 후 자동으로 듣습니다. 별도로 마이크 버튼을 누르지 않아도 됩니다. **듣기 준비됨**이 표시된 뒤 짧게 말하면, 튜터의 질문·안내가 끝날 때마다 다시 듣습니다. 방향은 다시 읽어 확인하며, 다음 듣기에서 **맞아요**라고 답해야 방향별 준비 안내를 시작합니다. **아니야**라고 답하면 후보를 버리고 방향을 다시 확인합니다. 끝내려면 **대화 종료**를 누르거나 듣는 중에 **대화 종료**라고 말하세요. 안내 중에는 마이크를 열지 않으며, 앱은 원시 음성을 저장하지 않습니다.
5. 음성 사용이 어려운 환경에서는 **시험 입력**을 사용합니다. 이 입력은 실제 음성 인식 성공으로 기록되지 않습니다.
6. 가상 모드에서 회전 정보·방향지시등·속도·브레이크·조향 시험값을 넣습니다. 실제 차량을 움직이는 제어는 하지 않습니다.
7. 마치고 복습에서 조작 타임라인을 다시 확인하고, 어려움·보통·수월함을 선택합니다. 다음 연습은 이 응답을 근거로 제안합니다.

## 대화 예시와 해석

| 입력 | 처리 |
|---|---|
| 왼쪽으로 차로 변경하고 싶은데 차가 많아 | 왼쪽 변경 준비 + 운전자 설명: 혼잡 |
| 차로 변경 도와줘 | 방향을 한 번 짧게 질문 |
| 오른쪽 | 직전 방향 질문의 답으로 처리 |
| 오른쪽 말고 왼쪽 | 명시적 방향 정정 |
| 옆 차들이 멈춰 있어 | 운전자 설명: 정지 상태. 앱이 직접 관측했다고 표시하지 않음 |
| 좌회전해야 해 | 좌회전 목적. 차로 변경 명령으로 바꾸지 않음 |
| 지금 들어가도 돼? | 주변을 직접 관측하지 못하므로 진입 시점 판단 불가 안내 |
| 다시 설명해 줘 / 잠깐 조용히 / 다시 시작 / 취소 | 재안내·일시 정지·재개·현재 요청 취소 |
| 대화 종료 / 그만 들어 줘 | 자동 듣기를 끝내고 연수를 일시 정지. 다시 시작할 때는 화면에서 재개 |

방향이 모호하거나 대화가 오래되면 이전 방향을 임의로 재사용하지 않습니다. **음성으로 받은 방향은 별도 확인 전에는 활성 요청 방향으로 사용하지 않습니다.** 에뮬레이터에서 왼쪽 합성 음성이 오른쪽으로 인식된 사례를 확인해 추가한 절차입니다. 화면에 직접 넣는 시험 문장은 STT 정확도 검증이 아니며 이 음성 확인 단계와 구분합니다. 차량이 적다는 말도 안전 판정으로 변환하지 않습니다. 밀도(많음/적음), 흐름(멈춤/이동), 접근 설명은 각각 구분합니다.

## 데이터 연결

```text
Pleos STT 최종 결과 ── 운전자 의도·진술 ─┐
Pleos Vehicle / AAOS ── 내 차 조작 ─────┤
NaviHelper TBT ───────── 다음 회전 ──────┤→ 연수 상태 → 음성 안내 → 기록·복습
명시된 시험 입력 ────── 가상 검증 ──────┘
```

- **음성:** `SpeechToText:3.3.1`, `TextToSpeech:3.3.1`, ON_DEVICE. 서버용 Client ID/Secret을 넣지 않습니다. 앱은 최종 인식 결과만 처리하며, 중간 결과·늦게 도착한 콜백·중복 결과를 실행하지 않습니다.
- **자차:** 기존 Vehicle 2.3.2 방향지시등·전륜 조향각·브레이크 눌림과 AAOS 실제 속도·기어를 읽습니다. 브레이크 압력이나 핸들 회전 수가 아닙니다. 각 항목의 수신 시각을 따로 유지하고 오래된 값은 미확인으로 바꿉니다. 초기 조회값은 조작 수행으로 세지 않습니다.
- **내비:** NaviHelper 3.0.5의 `onTBTInfo`와 `getTBTInfo`를 연결합니다. 다음 좌·우회전 종류와 남은 거리만 준비 안내에 사용합니다. 실제 차로 위치·빈 공간·경로 완료 여부를 추정하지 않습니다. 내비 서비스 연결 성공과 실제 TBT 정보 수신을 구분해 표시합니다.
- **가상 입력:** 실제 입력 모드와 별도이며 모드를 바꾸면 이전 진행을 초기화합니다. 가상 차량 신호는 Vehicle SDK 값을 변경하지 않습니다.
- **저장:** 프로필의 기록 저장 동의가 켜진 경우에만 최근 20회 연수를 로컬에 보관합니다. 회당 최대 160개 이벤트를 남깁니다. 반복되는 차량 관측부터 줄여 대화·안내·복습과 최신 차량 관측을 우선 보존하므로, 연속 주행 전체를 재현하는 기록 장치는 아닙니다. 음성 원본은 저장하지 않습니다. 진술 문장·출처·조작 기록이 포함될 수 있습니다. 삭제는 해당 모듈의 기록에만 적용됩니다.
- **복습:** 내 차의 조작 타임라인입니다. 주변 차량 영상·상대 차량·차로 변경 성공을 생성하지 않습니다. 급감속을 곧바로 실수로 채점하지 않습니다.

## 음성 환경과 실패 처리

### Mac에서 실제 마이크로 시험하기

1. macOS **시스템 설정 → 개인정보 보호 및 보안 → 마이크**에서 에뮬레이터를 실행한 앱의 접근을 확인합니다. 이번 환경에서는 **Codex** 권한이 꺼져 있었고 사용자가 직접 켰습니다. Android의 `STT_SERVICE` 허용과 별개입니다.
2. 권한을 바꾼 뒤에는 에뮬레이터를 완전히 종료하고 다시 실행합니다. 이번 Android Emulator **37.2.13** 환경에서는 아래 명령으로 실제 호스트 입력을 허용하고 재시작한 뒤 사람 목소리의 최종 인식 결과를 확인했습니다.

   ```bash
   bash scripts/run-emulator.sh -allow-host-audio
   ```

   다른 버전은 `emulator -help-allow-host-audio`로 옵션 지원 여부를 확인하세요. 앱이 호스트 권한을 대신 변경하지는 않습니다.
3. 에뮬레이터 **Extended Controls → Microphone → Enable Host Microphone Access**도 확인합니다. 버전에 따라 `Virtual microphone uses host audio input`으로 표시됩니다.
4. Mac 스피커가 음소거이면 튜터 안내가 들리지 않습니다. 앱의 **음성 안내**도 켜고, 저장·복습 시험은 프로필의 **프로필·연습 기록 → 이 기기에 저장**을 켠 상태에서 진행합니다.

`STT_READY`는 서비스 준비만 뜻합니다. 실제 입력 성공은 화면의 **인식한 말**, `STT_FINAL_RECEIVED`, 복습의 **운전자 음성** 기록으로 구분합니다. 디버그 로그의 RMS는 dB나 인식 정확도가 아닌 입력 신호 크기입니다. 콜백 수·범위·종료 단계만 진단하고 음성 원본과 인식 문장은 앱 진단 로그에 남기지 않습니다.

공식 설정: [Pleos 에뮬레이터 마이크 설정](https://document.pleos.ai/docs/connect/guide/getting-started/application-development/configure-pleos-connect-emulator), [Android 에뮬레이터 Microphone](https://developer.android.com/studio/run/emulator-extended-controls).

필요 권한은 `pleos.car.permission.STT_SERVICE`, `TTS_SERVICE`, 내비 조회용 `NAVI_ROUTE`입니다. Vehicle/AAOS 권한은 기존 설정을 사용합니다. 기기 내 모드는 서버 등록을 사용하지 않지만, 실행 환경의 Speech Service·권한·한국어 엔진이 필요합니다. 음성 인식·출력은 Pleos의 ON_DEVICE 방식입니다. 별도로 켜는 [외부 LLM 대화](LLM_TUTOR.md)는 인식이 끝난 문장과 대화·차량 문맥을 OpenAI에 보내며, 음성 원본을 외부 인식 서비스로 보내지는 않습니다.

Pleos SDK의 최소 CAAS 서비스 메타데이터는 4.1.29입니다. 서비스가 없거나 권한·엔진을 사용할 수 없으면 상태를 표시하고 입력을 종료합니다. TTS는 Pleos 출력 실패 시 Android 한국어 TTS를 시도하며, 둘 다 실패하면 화면 안내만 남깁니다. 실패를 성공처럼 표시하거나 입력하지 않은 문장을 만들어 처리하지 않습니다.

**함께 시작하기** 또는 **새 상황부터 다시 시작**으로 연수를 시작하면 자동 대화도 시작합니다. 별도 마이크 버튼은 누르지 않습니다. 처음 안내가 정상 종료될 때까지 기다리고, 완료 후 0.4초 간격을 두어 마이크 입력을 시작합니다. 질문에 답하거나 방향을 확인할 때마다 버튼을 누를 필요가 없습니다. 음성 출력을 꺼 둔 상태에서 시작하면 화면 답변을 보여주고 다시 듣습니다.

자동 듣기 도중 새로운 차량 조작·내비 안내가 생기면 입력을 중지하고 마이크 종료 처리를 기다린 뒤 안내합니다. 안내 후 다시 듣습니다. 이때 중단된 발화는 최종 문장으로 처리하지 않으므로, 필요하면 듣기 준비 후 다시 말해 주세요.

듣기 시간은 회당 최대 15초이며 입력이 없거나 인식·출력 오류가 나면 자동 대화를 끝냅니다. 화면 이탈·주행 제한·오디오 포커스 상실·연수 마무리도 마이크와 자동 재시작을 종료합니다. 화면으로 돌아와도 자동으로 마이크를 켜지 않으며 **대화 시작**을 다시 눌러야 합니다. 시험 문장 버튼·다시 듣기는 수동 입력으로 전환합니다. 중단된 안내를 나중에 자동 재생하지 않습니다. 상시 호출어와 안내 중 말 끊기 지원은 이번 구현에 포함되지 않습니다. 일시 정지 후에는 다시 시작을 선택합니다.

SpeechToText 3.3.1의 비동기 `stop()` 직후 `release()`하면 중지 요청이 서비스에 전달되지 않는 사례가 있어, 종료 요청 후 최대 1초 동안 연결을 유지하고 새 입력을 기다리게 했습니다. CAAS 4.2.10에서는 명시적 중지 때 종료 콜백이 관측되지 않아 이 제한된 대기를 적용했습니다. 이는 공식 종료 시간 보장이 아니며, 테스트는 앱 상태 외에 AudioFlinger의 실제 녹음 트랙 종료를 별도로 검사합니다.

앱의 별도 운영 로그에는 발화 원문을 남기지 않습니다. 다만 이번 개발 에뮬레이터의 **Pleos SDK/시스템 로그에서 인식 문장이 출력되는 것**을 확인했습니다. 앱의 기록 동의 설정이 플랫폼 로그까지 통제한다는 의미는 아닙니다. 실차 배포 시 플랫폼 로그 정책도 확인해야 합니다.

## 검증

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
python3 simulation/test/runners/run_scenario_qa.py
./gradlew :app:assembleDebugAndroidTest
python3 scripts/verify-lesson.py
```

단위 테스트는 방향 정정·부정 표현·모호한 요청·음성 방향 확인·대화 만료·신호 출처 변경·초기 조회·오래된 값·내비 중복·일시 정지·복습 제안을 확인합니다. 기기 테스트는 Pleos 에뮬레이터 한 대를 P·속도 0으로 두고 실행하며, 차량 속도 읽기 권한을 미리 허용해야 합니다. 기록 20회가 이미 있으면 기존 기록을 밀어내지 않도록 UI 테스트가 건너뛰어지고 검증 스크립트는 전체 통과로 보고하지 않습니다. 정상 실행 시 시험 연수 기록 한 개가 추가되며 기존 기록은 삭제하지 않습니다. 에뮬레이터 검증 결과와 직접 마이크 테스트 범위는 [검증 기록](INTERACTIVE_LESSON_VALIDATION.md)에 별도로 적습니다.

## 남은 실차 의존성

카메라 영상·주변 객체·후측방 경고를 실제로 수신하는 기능은 없습니다. 운전자의 설명은 주변 센서 관측과 다릅니다. 저속에서 옆 차량 접근·목표 차로 정체를 직접 알아야 하는 최종 기능은 주최 측/OEM 데이터 제공 및 권한 확인이 필요합니다. 주행 중 음성 사용 정책, 차종별 수신 주기·지연, 실제 한국어 발화 인식률과 교육 효과도 검증해야 합니다.

공식 문서: [STT](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/SpeechToText/intro), [TTS](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/TextToSpeech/intro), [NaviHelper](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/NaviHelper/intro).

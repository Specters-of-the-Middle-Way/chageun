# v0.6 — 막막한 순간에 먼저 반응하는 운전 코치

목표는 운전자가 메뉴에서 연수 과정을 찾는 대신, **실제 조작 중 어려움의 징후가 나타났을 때 짧게 도움을 받고, 주차 후 그 순간을 다시 연습하는 것**이다. 현재 구현은 이 흐름을 검증하는 정차용 가상 입력 프로토타입이다. 실제 주행 중 상황 감지·사용 승인을 완료한 앱은 아니다.

## 초보 운전자에게 먼저 필요한 도움

- “깜빡이는 켰는데 겁이 나서 속도가 계속 줄어요.” — 변화가 관측되면 서두르지 않도록 짧게 안내한다.
- “끼어들려다 가속을 너무 많이 했어요.” — 방향지시와 속도 변화의 조합을 보고 급한 조작을 줄이도록 안내한다. 합류할 빈 공간을 찾았다는 뜻은 아니다.
- “경고가 울리니까 더 당황해요.” — 차량 경고를 우선하고, 앱의 말이 겹치지 않게 한다. 정차 후 무슨 신호가 들어왔는지 확인한다.
- “다음에는 잘하고 싶은데 뭘 복습해야 할지 모르겠어요.” — 발생한 상황의 관측 순서를 저장하고 해당 튜터로 연결한다. 퀴즈나 순위 대신 도움을 받았던 순간을 돌아본다.

한 번의 속도 변화만으로 운전자가 불안하다거나 운전을 못한다고 평가하지 않는다. 변화는 도움을 제안할 단서다.

## 이번에 넣은 변수

| 변수 | 입력과 처리 | 현재 데이터 출처 |
|---|---|---|
| 방향지시등 | 꺼짐·왼쪽·오른쪽·비상등·미확인 | 상황 코치에서는 가상 입력. 기존 조작 연수는 실제 SDK 구독 검증됨 |
| 차량 속도 | km/h와 관측 시각. 최근 구간의 증가·감소를 계산 | 상황 코치는 가상 입력. AAOS 실제 속도 읽기는 기존 조향 연수에서 사용 |
| 차로 변경 경고 | 미확인·없음·왼쪽·오른쪽·양쪽 | 시험용 수동 입력. 실차 API 제공 여부 미확인 |
| 기어 | P·D·R·N·미확인 | 가상 기어. 화면의 D는 실제 기어를 바꾸지 않음 |
| 브레이크 | 눌림·놓임·미확인 | 가상 입력, 이벤트 근거·복습에 보관 |
| 조향 | 입력 각도·미확인 | 가상 입력. 기존 SDK 값은 전륜 조향각이며 핸들 회전 수가 아님 |
| 도로 문맥 | 직선도로·교차로·주차·미확인 | 수동 시험 조건. 내비로 자동 분류한 결과 아님 |
| 차량 경고음 우선 | 켜짐·꺼짐 | 가상 입력. 켜져 있으면 코치 음성을 겹치지 않고 기록만 남김 |
| 신호 시각·출처 | 관측 시각, 속도/방향지시/경고별 시각, SIMULATION/SDK | 오래되거나 역순인 신호를 제외. 출처가 바뀌면 관측 구간을 비움 |

**차로 변경 경고와 차선 이탈 경고는 같은 신호로 취급하지 않는다.** 이번 입력은 ‘차로 변경 경고’라는 교육용 추상화다. 후측방 충돌 경고, 차선 이탈 경고, 차로 유지 보조 개입을 실차에서 연결할 때는 각각의 API 의미·발동 조건을 먼저 구분해야 한다. 브레이크와 조향값만으로 실제 차로 변경 완료나 안전한 여유 공간을 추정하지 않는다.

## 자동 발동 흐름

1. 평소에는 말을 걸지 않고 관측한다. 깜빡이를 켜는 것만으로 튜터가 발동하지 않는다.
2. 방향지시가 켜진 상태에서 최근 3초 이내 속도 변화가 설정값에 도달하면 ‘방향지시 중 속도 감소/증가’ 사건을 만든다. 실제 차로 변경의 확정 판정은 아니다.
3. 차로 변경 경고 입력은 속도 변화와 별도로 우선 처리한다. 방금 속도 코칭이 나왔더라도 새 경고가 들어오면 경고 사건으로 올린다.
4. 화면에 어떤 변수로 반응했는지 표시하고, 해당 상황의 짧은 코치 안내와 복습 기록을 자동 생성한다.
5. 정차 후 ‘해당 상황 복습’으로 들어가 기록된 신호 순서를 재현한다. 주변 차량의 위치를 상상해 만들어내는 시뮬레이션은 아니다.

현재 검증 화면은 실제 차가 P·정차 상태일 때만 열린다. **완성형의 주행 중 경험은 짧은 음성 중심**, 화면을 보고 조작하는 자세한 시뮬레이션은 정차 후로 분리한다. DO 선언만으로 주행 중 사용이 허용되지는 않는다.

## 초기 실험값

- 관측 구간: 최근 3초, 최소 2초의 연속 관측.
- 속도 변화: ±12km/h. 법적 급가속·급감속 기준이나 현대자동차의 기준이 아니다.
- 저속 구분: 비교 구간의 두 속도가 모두 15km/h 미만이면 차로 변경 코칭을 하지 않는다.
- 신호 유효시간: 1.5초. 실차 신호의 실제 갱신 주기에 맞춰 재검증해야 한다.
- 반복 발화 대기: 15초. 같은 방향지시 시도는 속도 코칭을 반복하지 않는다. 새 경고는 우선 처리한다.
- P/R/N, 비상등, 방향지시 미확인, 교차로·주차 문맥에서는 차로 변경 코칭을 억제한다.
- 경고 없음과 경고 미확인은 구분한다. 어느 경우도 ‘안전하게 끼어들어도 됨’을 의미하지 않는다.

임계값은 `SituationConfig`로 분리했다. 실제 초보 운전자와 숙련 운전자의 정상적인 차로 변경, 교차로 감속, 정체, 오르막 등에서 오발동률·놓친 사건·발화 부담을 비교한 뒤 조정해야 한다. 빠르게 처리하거나 과감하게 끼어든 행동에 점수를 주지 않는다.

## 실제 주행에 연결하기 전에 필요한 정보

다른 튜터도 ‘상황 입력 → 근거 있는 감지 → 짧은 안내 → 정차 후 해당 상황 복습’ 구조로 확장한다. 이번에 자동 발동을 구현한 것은 위의 차로 변경 관련 세 상황이다. 나머지 튜터는 다음 변수의 제공 여부를 확인한 뒤 연결한다.

| 다음 튜터 | 필요한 변수 | 아직 자동 발동으로 연결하지 않은 이유 |
|---|---|---|
| 출발 준비 | 기어, 브레이크, 안전벨트, 출발 의도 | 시트·미러·주변 안전의 실제 확인과 구분 필요 |
| 후진·주차 | R, 실제 속도, 조향, 주차 경고, 주변 물체 | 현 프로토타입의 주행 제한과 경고 신호 접근 확인 필요 |
| 경사로 출발 | 경사, 브레이크, 진행 방향을 포함한 실제 속도 | 경사·밀림을 신뢰할 입력과 차종별 동작 확인 필요 |
| 교차로·우회전 | 내비 경로, 차량/보행 신호, 보행자, 속도 | 속도·기어만으로 횡단보도 보행자와 통행 가능 여부 판단 불가 |
| 좁은 골목의 교행 | 도로 폭, 내 차 제원, 맞은편 차·장애물 위치 | 해당 공간 정보를 현재 앱에서 확보하지 못함 |

실차 연결을 진행할 때 필요한 정보는 다음과 같다.

1. **대상 차종·연식·Pleos 버전과 시험 차량 유무.** 현재는 에뮬레이터 검증 단계다.
2. **주행 중 운전 코치의 앱 카테고리·음성 실행 허용 범위.** 일반 앱에 승인되는 권한과 OEM 기본 탑재 협약은 별도다.
3. **경고 신호의 정확한 종류와 API.** 후측방 경고인지, 차선 이탈 경고인지, 제어 개입인지와 방향·심각도·수신 주기를 확인해야 한다.
4. **실제 교통 상황을 더 구체적으로 판단하려면** 차선 문맥, 앞뒤 차량의 상대 거리·속도, 데이터 지연·신뢰도가 필요하다. 확보되지 않은 값은 미확인으로 남긴다.
5. **코칭 효과 검증 자료.** 교습 전문가와 초보 운전자의 동의된 시험에서 발화가 도움이 되는 순간, 오히려 부담인 순간을 구분해야 한다.

위 정보가 없어도 이번 시뮬레이션과 규칙 엔진은 실행할 수 있다. 사용자가 값을 임의로 제공한다고 실차 접근 권한이나 센서 신뢰도가 확보되는 것은 아니다.

## 공식 근거

- [Pleos SDK 개요·권한 정책](https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/): 현재 공개 모듈과 승인 범위. 현재 확보한 Vehicle 2.3.2에서 전방 영상·차선·주변 객체 API를 확인하지 못했다.
- [주행 제한 개발 가이드](https://document.pleos.ai/en/docs/pleos-only/vehicle-app-developer-guide/driving-restriction-development-guide): 주행 제한 상태와 기능별 제한 준수.
- [API 호환성과 가용성](https://document.pleos.ai/en/docs/pleos-only/vehicle-app-planning-guide/api-compatibility-availability): 제공되지 않는 특수 차량 속성의 사전 검토.
- [현대자동차그룹 ADAS 설명](https://www.hyundaimotorgroup.com/ko/amp/CONT0000000000016227): 후측방 충돌방지 보조 등 기능별 역할. 해당 기능이 차량에 존재한다는 사실과 일반 앱이 그 데이터를 읽을 수 있다는 사실은 구분한다.

확인일: 2026-11-08. 과거 검색 색인의 ADAS 문서를 현재 사용 가능한 API로 간주하지 않는다.

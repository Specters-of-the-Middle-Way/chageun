# 차근 — 내 차 안의 다정한 운전 튜터

## 현대자동차그룹 차량용 앱 개발 공모전 앱 소개서 초안

작성일: 2026년 11월 12일 · 초안 v2 (프로토타입 보완 반영)

> **출발 준비부터 질문, 연습, 복습까지. 초보 운전자가 운전 요령을 차근차근 익히도록 돕습니다.**

차근은 운전이 낯선 사용자를 위한 Pleos Connect 차량용 앱입니다. 현재 프로토타입은 **정차 상태에서의 출발 준비, 날씨에 따른 조언, 글레오와의 운전 학습 대화, 가상 주행·주차 연습, 연습 기록과 복습**을 제공합니다.

**주행 중 음성 대화는 현재 구현 범위에 포함하지 않습니다.** 본선 진출 후 플랫폼의 허용 조건을 확인해 우선 확장할 기능으로 계획하고 있습니다. 실제 도로 기반 코스 추천과 센서 기반 코칭은 별도의 확장 후보로 구분합니다.

## 1. 기획 배경과 대상 사용자

면허 취득 후에도 자신의 차량에서 무엇을 먼저 확인하고, 어려운 운전 상황을 어떻게 연습해야 할지 막막할 수 있습니다. 시트와 미러를 맞추는 일, 차량 기능을 찾는 일, 주차 순서를 기억하는 일부터 설명과 반복 연습이 필요합니다.

차근은 다음 사용자를 대상으로 합니다.

- 처음 차량을 구매해 차량 조작과 출발 준비가 낯선 운전자
- 오랫동안 운전을 쉬었다가 다시 시작하는 운전자
- 차로 변경·회전·주차 등 특정 상황을 반복해서 익히고 싶은 운전자

차근의 목표는 **차량 안에서 준비하고, 궁금한 내용을 질문하고, 가상 상황으로 연습한 뒤 다음 과제를 정하는 학습 흐름**을 제공하는 것입니다.

## 2. 서비스의 핵심 가치

### 출발 전 확인을 하나의 흐름으로

운전자 설정, 시트·미러·벨트 안내, 출발 전 체크리스트, 현재 날씨에 따른 조언을 연결합니다. 사용자가 확인할 항목을 단계별로 제시하고, 지원되는 차량 상태 정보는 동의 후 함께 확인하도록 구성했습니다.

### 글레오에게 묻고 이어서 배우기

사용자는 글레오를 통해 차근의 연수 대화를 시작하고, 운전 요령의 이유나 순서를 이어서 물을 수 있습니다. 차근이 제공하는 학습 요점을 바탕으로 글레오가 음성 답변을 전달합니다. 현재는 정차 상태에서 사용할 수 있습니다.

### 가상 연습을 복습과 연결

화면 속 차량과 도로를 이용해 조작 순서와 상황별 확인 요령을 연습합니다. 연습 후 사용자가 어렵다고 느낀 과제를 남기면 다음 복습 항목을 추천합니다. 가상 연습 결과와 사용자의 자기평가는 구분해 다룹니다.

## 3. 현재 구현된 기능 — 프로토타입 제공 범위

아래 기능은 현재 앱에 구현된 범위입니다. 교육과 가상 연습의 구현 여부를 기준으로 하며, 실제 도로에서의 자동 판단이나 실차 검증 완료를 의미하지 않습니다.

| 기능 | 현재 제공하는 내용 | 적용 범위 |
|---|---|---|
| **운전자 설정·출발 준비** | 체격 등 프로필 입력, 시트·미러·벨트 등 운전 환경 9단계 안내, 출발 전 7개 항목 확인 | 운전자가 직접 조절·확인하는 흐름입니다. 실제 시트·미러 자동 이동은 제공하지 않습니다. |
| **현재 날씨와 운전 조언** | 앱 실행 시 현재 위치 날씨 조회, 비·눈·안개·저온 등에 맞는 조언과 자동 음성 안내 | 위치를 받지 못하면 경기도 성남시 수정구 복정동 기준임을 표시합니다. 시동 자동 실행이나 실제 노면 감지는 아닙니다. |
| **글레오와 함께하는 연수** | 차로 변경, 미러·사각지대, 회전 준비, 출발·정지, 주차 준비, 빗길, 야간 운전의 질문과 후속 설명 | P·정차 상태에서 이유·순서·주의점 등을 물을 수 있습니다. 주행 중 대화는 미구현입니다. |
| **음성으로 기능 요청** | 글레오를 통한 출발 준비 확인, 날씨 조언, 가상 주차 연습 시작 | 준비 항목이 미완료이면 먼저 준비 확인을 안내합니다. 별도의 OpenAI API 키 입력이 필요하지 않습니다. |
| **차량 기능·운전 기본 교육** | CN7 2024 공조·열선·와이퍼·등화 등 기존 7개에 좌석 통풍·어린이 보호 잠금을 더한 9개 기능. 새 두 기능의 조건·조작·직접 확인·문제와 해설을 제공합니다. | 수동/자동 공조와 해당 장치 장착 여부를 직접 확인합니다. 공식 설명서의 출처와 쪽을 표시하며 설명서 전체나 실제 작동 감지를 제공하지 않습니다. |
| **가상 주행·주차 연습** | 18개 주행 과제와 기존 주차 연습. 차로 변경·골목 교행·합류는 각각 두 상황에서 접근 차량·가려진 보행자·막힌 통로를 살피고 대기·취소를 선택합니다. | 화면에 그리는 객체와 과제 판정이 같은 상태를 사용합니다. 모든 수치·판정은 가상 연습에만 적용하며 실제 차량을 움직이거나 진입을 허가하지 않습니다. |
| **이중 주차 시각 교육** | 다른 차 앞의 주차 배치, 출차 경로와 보행·비상 통행 공간을 보고 위치나 대응을 고릅니다. 세 상황의 선택별 해설·재시도·복습을 제공합니다. | 평행 주차와 구분한 교육입니다. 실제 주차 물리·주변 센서 판단은 제공하지 않으며 N단 유지나 주차 브레이크 해제를 공통으로 지시하지 않습니다. |
| **연습 기록과 다음 과제** | 동의 시 로컬 기록 저장, 연습 복습, 사용자가 어려웠다고 선택한 과제에 따른 다음 과제 추천, 중단 후 복귀 | 자기보고와 규칙을 바탕으로 추천합니다. 실제 운전 실력 자동 평가나 AI 실도로 코스 추천은 아닙니다. |
| **차량에 맞춘 표시와 화면 구성** | 아반떼 CN7 가솔린 1.6 기준 정보, 전기차 관련 내용의 조건부 표시, 준비·연습·학습/기록으로 묶은 메뉴 | 앱의 기준 차량 설정을 따릅니다. 실제 연결 차량을 자동 식별하는 기능은 아닙니다. |

### 일부 연동된 기능과 남아 있는 제한

차량 데이터 사용 동의와 필요한 권한을 바탕으로, 지원되는 시트·안전벨트·차량 경고·일부 조작 신호를 읽는 기능이 들어 있습니다. 읽을 수 없거나 오래된 값은 정상 상태로 추정하지 않습니다.

위치 표시와 내비게이션 목적지 요청도 일부 연결돼 있습니다. 다만 현재 에뮬레이터의 **기본 내비게이션 흰 지도·위치 문제는 미해결**이며, 실제 경로 안내가 정상 작동하는 완성 기능으로 소개하지 않습니다. 현재의 맞춤 코스는 실제 도로와 분리된 가상 코스입니다.

## 4. 현재 프로토타입 이용 시나리오

차량이 P·정차 상태이고 앱 사용이 허용되는 상황에서 다음 흐름으로 이용합니다.

1. **차근 실행:** 현재 날씨와 해당 날씨에 맞는 운전 조언을 확인합니다.
2. **출발 준비:** 운전 환경 안내에 따라 시트·미러·벨트를 직접 확인하고 출발 전 체크리스트를 완료합니다.
3. **궁금한 내용 질문:** 글레오를 부른 뒤 “차근 연수 대화 시작해 줘”라고 말합니다.
4. **이어지는 학습:** “차로 변경”을 주제로 답변을 듣고, “순서대로 좀 더 자세히 알려줘”라고 추가 질문합니다.
5. **가상 연습:** 준비 상태를 확인한 뒤 화면에서 주행 또는 주차 과제를 연습합니다.
6. **복습:** 동의한 경우 연습 기록을 남기고, 어렵게 느낀 과제를 다음 연습에 반영합니다.

글레오가 듣기를 종료한 경우에는 다시 호출합니다. 차근 화면에는 요청 도착 여부와 학습 요점이 표시돼, 차근의 연수 기능으로 연결됐는지 확인할 수 있습니다.

## 5. Pleos 활용과 현재 검증 범위

차근은 Pleos 차량 환경에서 음성, 차량 상태, 학습 화면을 연결했습니다.

| 활용 요소 | 현재 연결 방식 |
|---|---|
| 글레오 | 사용자의 음성 요청을 차근의 연수·준비·날씨·가상 주차 기능으로 연결하고 결과를 음성으로 전달 |
| 차량 상태 정보 | 지원·권한·동의 조건에서 차량 값을 읽고 준비 확인과 학습에 활용 |
| 차량용 화면 | 큰 글씨와 선택 영역, 목적별 메뉴, 화면 크기에 대응하는 배치 |
| 학습 기록 | 사용 동의를 바탕으로 연습 기록을 로컬에 저장하고 복습에 활용 |

**Pleos Connect 2.1 / Android 14 에뮬레이터에서 주요 이용 흐름을 검증했습니다.** 앞선 글레오 연수 작업에서는 실제 PC 마이크를 통해 ‘대화 시작 → 차로 변경 질문 → 단계별 추가 설명’이 차근에 전달되는 것을 사용자 확인, 앱 수신 로그, 화면으로 확인했습니다. 이번 후속 보완의 글레오 자동 검사는 직접 요청 전달과 응답·문맥 처리를 확인한 것으로, 실제 마이크 발화나 글레오 최종 음성의 청취 검증과 구분합니다.

후속 보완에서는 **18개 주행 과제를 각각 화면 조작으로 끝까지 완료**하고, 이중 주차의 오답·재시도·복습, 화면 이탈 후 준비 확인과 명시적 재개를 확인했습니다. 완료 상태를 직접 주입한 검사를 실제 조작 성공으로 계산하지 않았습니다.

같은 듣기 요청의 연속 입력을 합치고 이전 출력의 중지를 확인한 뒤 새 출력을 시작하도록 수정했습니다. Pleos 음성과 기본 음성 파일, Android 대체 출력, 자동 날씨와 글레오 요청 처리의 검증을 구분합니다. 이 에뮬레이터의 Android 대체 TTS는 초기화 불가로 음질을 확인하지 못했습니다. **간헐적인 음성 깨짐의 원인은 미확정**이며 재생 완료 로그만으로 해결됐다고 소개하지 않습니다. [검사 조건과 남은 확인 사항](PROTOTYPE_IMPROVEMENTS_2026-11-12.md)을 참고합니다.

이 검증은 에뮬레이터에서의 기능 확인입니다. 실차 환경의 동작, 주행 중 사용, 운전 능력 향상 효과까지 검증한 것은 아닙니다.

## 6. 본선 진출 후 추가할 기능 — 우선 추진 계획

### 주행 중 글레오 요청형 음성 대화

**현재 상태: 미구현. 프로토타입 범위에서는 구현을 보류했으며, 본선 진출 후 검토할 우선 확장 기능입니다.**

정차 중에 제공하는 학습 대화를 확장해, 주행 중에도 사용자가 글레오를 불러 질문하면 화면 조작 없이 짧은 일반 운전 조언을 받을 수 있도록 개발을 추진합니다.

| 항목 | 본선 이후 목표 |
|---|---|
| 이용 방식 | 운전자가 필요할 때 음성으로 질문하고 짧은 답변 듣기 |
| 화면 동작 | 학습 화면을 열거나 터치할 필요 없이 요청 처리 |
| 안내 범위 | 운전 요령과 확인 순서 등 일반적인 학습 조언 |
| 음성 처리 | 내비게이션·차량 경고 등 다른 음성과의 중단·재개 및 우선순위 검증 |
| 착수 조건 | 플랫폼의 주행 중 사용 조건과 허용 범위 확인 |
| 확인 목표 | 주행 상태 전환과 화면 전환 시에도 허용된 범위의 음성 요청·응답이 동작하는지 검증 |

이 기능은 사용자의 질문에 답하는 대화입니다. 주변 차량을 관측해 “지금 진입해도 된다”고 판단하거나, 실제 차량 조작을 지시하는 기능으로 계획하지 않습니다. 플랫폼 검토 결과에 따라 제공 범위를 조정합니다.

## 7. 본선 이후 단계적으로 검토할 확장 후보

아래는 기획 방향을 발전시키기 위한 후보입니다. **현재 구현된 기능이나 개발 일정이 확정된 기능이 아니며**, 데이터와 연동 환경을 확보한 항목부터 범위를 정합니다.

| 확장 후보 | 사용자에게 제공하려는 가치 | 먼저 확보·검증할 사항 |
|---|---|---|
| **실제 도로와 연결된 연수 코스** | 가상 코스를 넘어 목적지와 실제 경로를 따라 연습 준비 | 지도·경로 제공 환경, 목적지 검색·선택, 내비 안내 결과 확인 |
| **약점·목적을 반영한 AI 코스 추천** | 어렵게 느낀 과제를 연습할 도로 후보와 선택 이유 제안, 출퇴근 왕복 코스와 연결 | 실제 경로 후보, 도로 특성·난이도 기준, 추천의 적절성 검증 |
| **상황별 자동 음성 코칭** | 유효한 차량·도로 정보에 맞춰 필요한 순간에 짧은 안내 제공 | 신호 접근 범위·최신성, 주행 중 실행 조건, 안내 빈도와 음성 우선순위 |
| **경사·위험 장소·보호구역 안내** | 실제 위치에 대응하는 사전 확인 요령 제공 | 신뢰할 수 있는 도로 데이터, 정보 갱신, 위치와 구역의 일치 검증 |
| **센서 기반 주차 도움 — 장기 검토** | 실제 거리·방향 정보를 활용한 주차 보조 안내 | 공개 센서 접근 경로, 거리 단위·지연·누락 검증. 현재 공모전 범위에서 ADAS SDK를 사용할 수 없다는 기존 안내를 전제로 검토 |

현재 프로토타입에는 설명서 두 기능, 이중 주차 시각 교육과 추가 가상 교통 상황을 보완했습니다. 설명서의 추가 범위 확대와 음질 원인 확인은 계속 보완할 과제입니다. 주행 중 글레오 대화와 실도로·실센서 확장은 위의 본선 이후 계획으로 구분합니다.

시동 자동 실행은 현재의 ‘앱 실행 시 날씨 안내’로 대체한 상태를 유지합니다. 실제 시트·미러 자동 조절과 자율주행 기능은 확정된 본선 개발 범위에 포함하지 않습니다.

## 8. 기대 효과와 향후 평가 방향

차근은 출발 전 확인을 습관화하고, 모르는 내용을 질문하기 쉽게 만들며, 반복 연습할 과제를 구체적으로 정하는 데 도움을 주고자 합니다. 차량 안에서 준비·설명·연습·복습을 이어가는 것이 서비스의 중심입니다.

이 효과는 현재 측정된 성과가 아닌 **검증할 목표**입니다. 향후 사용자 평가에서는 다음을 확인할 계획입니다.

- 도움 없이 출발 준비 흐름을 완료할 수 있는지
- 글레오 질문과 후속 설명을 통해 운전 요령을 이해했는지
- 가상 연습 후 자신이 어려워한 과제와 다음 연습 목표를 설명할 수 있는지
- 음성 길이·반복 횟수·화면 구성이 부담스럽지 않은지

실제 운전 능력 향상이나 사고 감소 효과는 별도의 평가 없이 성과로 주장하지 않습니다.

## 9. 제출 양식용 짧은 소개문

> 차근은 운전이 낯선 사용자를 위한 Pleos Connect 차량용 운전 튜터입니다. 현재 프로토타입은 출발 준비 체크리스트, 위치 기반 날씨 조언, 정차 중 글레오 대화, 가상 주행·주차 연습, 기록과 복습을 제공합니다. 사용자는 궁금한 운전 요령을 질문하고 추가 설명을 들으며 다음 연습 과제를 정할 수 있습니다. 본선 진출 시에는 플랫폼의 허용 조건을 확인해 주행 중 요청형 음성 대화로 확장할 계획입니다. 실제 도로 기반 맞춤 코스와 데이터 기반 상황별 코칭은 연동 환경을 확보한 뒤 단계적으로 검토합니다.

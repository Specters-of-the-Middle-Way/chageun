# 차량 기능 익히기 화면 정리

작업일: 2026-11-12 · 대상: 준비와 연습 → 차량 기능 익히기 · Pleos Connect 2.1 에뮬레이터

## 변경 내용

| 항목 | 반영 내용 |
|---|---|
| 설명서 선택 | 내 차량 설명서·가상 패널과 2024 CN7 수동·자동 공조를 상단 카드에서 선택한다. 선택 상태를 녹색으로 표시한다. |
| 기능 목록 | 실내 온도(에어컨·난방·좌석 열선)와 시야 확보(앞유리 김서림·뒷유리 열선·와이퍼·전조등)로 묶었다. |
| 단계 안내 | 선택한 기능과 현재 단계, 설명, 학습 상태, 공식 설명서 출처를 연한 녹색 카드에 모았다. 내부 문서 식별번호는 화면에서 제외하고 사용자에게 필요한 연식·공조 사양·쪽 번호를 표시한다. |
| 조작 버튼 | 이전·음성으로 듣기·다음 단계와 학습 확인 버튼을 하단에 고정했다. 완료 전 조건과 완료 표시를 구분하고 완료 후 중복 확인은 비활성화한다. |
| 가독성 | 화면 제목 30sp, 기능 제목 28sp, 핵심 설명 26sp, 선택·진행·상태 20~24sp, 출처·보조 설명 18~19sp. 버튼 최소 높이는 64dp다. |
| 긴 글·좁은 창 | 안내문의 고정 높이를 제거했다. 긴 설명은 줄바꿈하고 좁은 창은 카드 세로 배치와 본문 스크롤로 대응한다. |
| 단계 유지 | 같은 기능이나 같은 공조 사양을 다시 선택해도 현재 학습 단계를 초기화하지 않는다. 가상 패널에서 공식 설명서로 돌아올 때 앞서 선택한 공조 사양을 유지한다. |

기존 CN7 설명서의 조작 안내와 순수 학습 상태 모델은 변경하지 않았다. 실제 차량 기능을 제어하지 않으며, 공식 설명서는 끝 단계 확인, 가상 패널은 끝 단계 확인과 모의 작동을 거쳐야 완료된다. 기록 동의가 없으면 완료 상태를 저장하지 않는다. 안내가 없는 기능은 사용설명서 확인을 안내한다.

## 검증 결과

| 검사 | 결과와 범위 |
|---|---|
| 빌드 | `assembleDebug`, `testDebugUnitTest`, `lintDebug`, `assembleDebugAndroidTest` 통과 |
| 단위 테스트 | 379개 통과, 실패·오류·건너뜀 0개 |
| Android Lint | 오류·경고 0개 |
| 화면 계측 2개 | 공식 설명서 7개 기능 × 수동·자동 공조 및 가상 패널 7개 기능, 총 21개 학습 조합의 전체 단계·완료 조건을 확인했다. |
| 가독성·고정 버튼 | 1,707×1,018dp / 글자 배율 1.2·1.6, 1,100×650dp / 배율 1.2에서 텍스트 잘림·말줄임 없음, 터치 영역과 하단 확인 버튼의 화면 내 배치를 확인했다. |
| 실제 화면 흐름 1개 | 실제 MainActivity에서 수동 공조 7개 기능, 자동 공조 앞유리 김서림, 가상 패널 7개 기능의 학습 완료를 확인했다. 이전·다음 이동, 모의 작동 전 완료 차단, 기타 기능 안내, 같은 기능 재선택 시 단계 유지도 확인했다. |
| 기존 회귀 검사 1개 | 와이퍼·전조등·뒷유리 열선의 출처 표시와 모든 단계 후 완료, 실제 설명서에 모의 조작 버튼이 없는 것을 확인했다. |

기기 검사 **4개 통과**. 기본 창의 실제 화면을 캡처해 기능 선택·안내·하단 버튼을 함께 볼 수 있는 것을 확인했다. 검사 후 기록 동의·음성·날씨 설정을 복원했고 기존 학습·연습 저장 데이터의 불변을 확인했다. 이번 UI 검사에서 음성의 청감 품질이나 실차 기능 작동을 새로 검증한 것은 아니다.

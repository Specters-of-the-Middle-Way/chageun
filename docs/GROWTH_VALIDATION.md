# 성장 튜터 v0.4 검증

2026-11-08 · Pleos 에뮬레이터 2.1.0 / Vehicle SDK 2.3.2.

## 확인 결과

- debug·release 빌드와 Android lint 통과.
- 단위 테스트 72개 통과, 실패·오류 0개. 신규 성장 엔진 테스트 15개 포함.
- 에뮬레이터에서 체격·자세 확인 6단계, 9개 과정 27개 상황을 실제 UI로 완료.
- 오답 음성·정지 도식·재시도, 90점 결과, 모든 정답 선택·오답 선택의 로컬 저장 확인.
- 가상 조향 슬라이더의 접근성 상태 변화, 감사 시연 중 실제 방향지시등 Off 유지 확인.
- 기존 최고점 보존, 100점 재연습의 포인트 중복 적립 방지 확인.
- 강제 종료·재실행 후 완료 기록·최고점 유지, 예시 순위 표기, 기존 SDK 메뉴 연결 확인.
- 미리보기 완료 후 저장된 점수·프로필·기록이 전혀 바뀌지 않음 확인.
- R 전환 시 플랫폼 UX 제한·실습 버튼 비노출·음성 중지 확인. 시스템 후방 카메라가 앱 위에 표시될 수 있어 앱 문구 노출을 필수 조건으로 삼지 않았습니다.
- 더블클릭 실행 스크립트가 기존 Pleos 기기를 재사용하며 설치·실행하는 경로 확인.
- 음성 자산 134개 해시와 성장 과정 81개 문구/음성 참조의 일치 확인.

## 실행 경로

앱 기본 화면 → 체격 선택 → 자세 확인 6단계 → 1장 두 과정 → 2장 세 과정 → 3장 네 과정 → 성장 기록. 기존 SDK 실습은 ‘실제 SDK 조작 실습’으로 들어갑니다.

## 평가 범위

이번 점수는 가상 상황의 선택·확인 순서를 평가합니다. 실제 차량 신호로 위반을 감지하거나 운전자를 인증하지 않습니다. Canvas 자동차는 작성된 예시 경로를 따라 움직이며 실제 차량의 축거·회전반경·도로 폭·장애물을 모델링하지 않습니다. 가상 핸들은 바퀴 방향과 핸들 그림만 바꿉니다.

키 범위·몸 비율 입력은 안내를 개인화하는 참고값입니다. 기본 세팅 완료는 운전자가 직접 확인한 체크이지 SDK로 좌석 위치를 확인한 결과가 아닙니다. 법규 근거와 조건은 [GROWTH_SOURCES.md](GROWTH_SOURCES.md)를 참고합니다.

## 검증 방법

- 기존 조작 엔진 테스트와 신규 성장 과정 테스트를 함께 실행합니다.
- 새 엔진 테스트는 과정 구조, 정답/오답 상태 전이, 정답 전 다음 단계 금지, 알 수 없는 입력, 중복 입력, 완료 후 불변, 점수 경계를 확인합니다.
- 실제 에뮬레이터 UI로 9개 과정 27단계, 오답 재안내, 가상 핸들 표시, 감사 표시 시연, 로컬 결과·최고 점수, 재실행 복구를 확인합니다.
- 감사 시연 전후 콘솔의 실제 방향지시등 상태를 확인해 실제 차량 신호를 바꾸지 않는지 검사합니다.
- 진행·순위는 완료 결과만 반영하며 이전 최고점이 낮아지지 않는지, 같은 100점 과정을 반복해 포인트가 늘지 않는지 검사합니다.
- 모든 화면은 기존 정차 UX 제한을 유지합니다. 다른 화면으로 이동하거나 사용이 제한되면 음성과 애니메이션을 중지합니다.

## 실제 차량에서 아직 확인하지 않은 항목

실차별 권한·신호 의미, 실도로 상황 인지·안전 경로, 실제 교육 효과와 운전 능력 향상, 배포 심사·실차 주행 중 UX 허용 범위. 본 시연은 실차 도로주행 연수나 면허 취득을 대체하지 않습니다.

이번 작업 전 성장 기록 파일이 없었음을 확인했습니다. 검증으로 생성한 성장 기록은 별도 로컬 백업 후 앱의 초기화 기능으로 정리해, 사용자가 처음부터 시작할 수 있게 했습니다. 기존 SDK 실습 기록은 유지했습니다.

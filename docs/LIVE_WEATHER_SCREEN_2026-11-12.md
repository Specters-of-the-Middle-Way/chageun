# 현재 위치 날씨 화면 정리

## 변경 내용

| 항목 | 반영 내용 |
|---|---|
| 현재 날씨 | 지역·기온·날씨·예보 시각을 녹색 카드에 모았다. 기온과 날씨는 40sp, 지역은 24sp로 표시한다. |
| 운전 조언 | 출발 전 조언을 별도 흰색 카드에 23sp로 표시하고 여러 문단이 줄바꿈되도록 했다. |
| 설정 | 지역 정보 전송 동의·앱 실행 시 자동 조회·조회 후 자동 읽기를 별도 카드로 정리했다. 스위치와 문구를 분리해 긴 제목·설명이 겹치거나 잘리지 않도록 했다. |
| 조회·듣기 | 주요 버튼을 화면 하단에 고정했다. 조회 중에는 조회 취소, 결과가 있을 때는 조언 듣기를 표시한다. 버튼 글씨는 20sp, 최소 높이는 64dp다. |
| 정보 없음 | 조회 전·동의 해제·조회 중·취소·실패·정보 만료 상태를 날씨 카드에서 안내한다. 새 조회 결과를 받으면 맨 위의 날씨와 조언을 보여준다. |
| 화면 구성 | 다른 연습 화면과 같은 제목·메뉴·카드·강조색을 적용했다. 넓은 창은 좌우 배치, 좁은 창은 세로 배치이며 본문만 스크롤된다. |
| 참고 정보 | Open-Meteo 출처·라이선스·기상 모델 예보 표시와 날씨별 대응 교육 연결을 하단 카드에 모았다. |

좌표를 소수점 두 자리로 줄이는 정책, 위치 미확인 시 복정동 대체 조회, 위치·날씨 미저장, 30분 최신성 검사, 설정 저장, 음성·정차·화면 이탈 조건은 유지했다. 기존 지역 선택 버튼을 다시 추가하지 않았다.

# v0.6 검증 결과 — 상황반응 코치와 직접 조작 연수

확인일 2026-11-08. 실제 차량 시험이 아니라 Pleos 2.1.0 / Android 14 에뮬레이터, 현재 차량 사용자 10에서 수행했다. 설치 버전은 0.6.0 / versionCode 6이다.

## 빌드·자동 검사

- Debug APK, Release APK 빌드와 lint 통과.
- 단위 테스트 **123개 통과**: 기존 조작·학습 72개, 가상 주행 31개, 상황 감지 20개.
- 한국어 기본 음성 **160개** 포함. 새 상황 코치 음성 3개의 실제 번들 재생 시작을 로그로 확인.
- Release 매니페스트에 INTERNET 권한·DO 선언을 추가하지 않았다. 주행 제한을 우회하지 않는다.

## 에뮬레이터에서 확인한 사용자 흐름

| 흐름 | 확인 결과 |
|---|---|
| 방향지시 + 감속 | 시간 순서의 가상 입력으로 SPEED_DROP 자동 생성, 음성, 근거·입력 저장 |
| 방향지시 + 속도 증가 | SPEED_RISE 자동 생성, 다른 안내와 올바른 방향 기록 |
| 차로 변경 경고 | 경고 단독 입력도 LANE_WARNING 자동 생성 |
| 차량 경고음 우선 | 추가 코치 발화를 억제하고 기록만 저장. 우선 상태 해제 후 지연 재생하지 않음 |
| 중복·복습 | 같은 상황에 기록을 반복 생성하지 않음. 저장 입력 재현과 앱 재시작 후 복습 유지 |
| 앱 이탈·주행 제한 | 입력·음성 중단, P 복귀·화면 복귀 때 자동 재개하지 않음 |
| 가상/차량 입력 분리 | 가상 기어·페달·속도를 바꿔도 실제 에뮬레이터 차량 기어 P·속도 0 유지 |
| 실제 SDK 방향지시 연수 | 반대 방향 조작 시 교정 음성, 끄기 후 재시도, 올바른 순서 완료·저장 |
| 연수 연결 | 자세 가이드에서 코치 홈 복귀, 방향지시 완료에서 조향 안내 화면 연결 |
| 가상 출발·정지 | 브레이크 없는 D 선택 교정, 브레이크·D·가속·정지·P 조작으로 완료 |
| 가상 횡단보도 | 직접 제동 → 보행자 대기 → 적신호 대기 → 가상 녹색 후 직접 가속으로 완료 |
| 가상 연수 중단 | 백그라운드·주행 제한에서 누른 페달을 해제하고 명시적으로 재개 |

`verify-situation.py`와 `verify-coach.py`가 **최종 v0.6 설치본에서 모두 통과**했다. 후자는 이전 v0.5에 도입한 조작 연수의 회귀 검사라 마지막 로그 문구에 v0.5가 남아 있다. 테스트는 앱 내부 상태를 성공으로 주입하지 않고 UI 조작·가상 콘솔 입력, 저장 기록, 음성 로그로 확인한다.

상황 시험 중 UIAutomator가 두 차례 idle 상태 경고를 출력했지만, 이후 실제 저장 사례·음성·화면 전환을 확인하는 검증은 모두 완료됐다. 화면 스크린샷도 확인했다. 이 결과를 실차 연수 효과나 주변 인식의 정확도로 해석하지 않는다.

## 추가 확인이 필요한 범위

실차 차종별 신호 접근과 갱신 주기, 경고 종류별 API, 주행 중 앱·음성 허용, 주변 인식 정보, 교습 전문가 검토, 초보 운전자에게 실제 도움이 되는지의 검증은 남아 있다. ±12km/h/3초 등의 값은 시험용 가설이며 안전·법규 기준이 아니다.

기존 SDK 조향의 실험 조건은 `STEERING_VALIDATION.md`, 제품 방향과 변수는 `SITUATION_COACH.md`를 참고한다.

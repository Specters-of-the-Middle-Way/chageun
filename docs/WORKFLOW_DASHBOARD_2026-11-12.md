# 준비와 연습 화면 정리 — 2026-11-12

길게 나열됐던 메뉴를 목적에 따라 세 영역으로 정리했다. 에뮬레이터의 기본 앱 폭에서는 주요 기능을 스크롤 없이 고를 수 있다.

| 영역 | 구성 | 이용 방식 |
|---|---|---|
| 출발 전 확인 | 준비 상태, 출발 준비하기, 오늘 날씨, 차량 상태, 차량 기능 배우기 | 왼쪽에서 출발 전 확인을 시작한다. 날씨는 현재 위치 날씨 화면으로 연결된다. |
| 운전 연습 | 주행 연습, 주차 연습, 차로 변경, 맞춤 코스 | 오른쪽의 큰 카드 네 개로 바로 선택한다. 주행 연습은 강조색으로 구분했다. |
| 배우고 돌아보기 | 운전의 기본, 연습 기록 | 교육과 복습을 아래쪽에 묶었다. |

중단한 연습이 있으면 위쪽에 과제 이름과 다시 시작 버튼을 표시한다. 메모리에 남아 있는 연습은 준비 확인 후 이어가고, 저장된 체크포인트만 있으면 해당 과제를 처음부터 다시 시작하는 기존 동작을 유지했다.

제목과 설명의 글자 크기·굵기를 구분하고 카드 여백, 아이콘, 누름 효과를 맞췄다. 첫 화면의 긴 음성 기능 설명은 덜어냈고, 상단 음성 안내 설정은 유지했다. 화면 폭이 줄어들면 영역을 세로로 배치하고, 폭이 매우 좁거나 글자가 크게 설정되면 카드와 복귀 안내도 한 열로 배치한다.

## 동작 범위

- 출발 준비 버튼은 기존 운전 환경·준비 확인 흐름을 연다. 준비 여부를 임의로 완료 처리하지 않는다.
- P·정차 조건, 연습 전 준비 확인, 화면 이탈 시 중단, 동의와 저장 설정은 기존 동작을 사용한다.
- 차량 상태와 내비 메뉴는 기존 화면에 연결한다. 기본 내비의 지도·위치 문제에 대한 구현 판정은 바꾸지 않는다.
- 기획 대비 기능 등급은 변경하지 않는 화면 구성 개선이다.

## 검증

최종 APK를 데이터 삭제 없이 에뮬레이터에 업데이트 설치했다.

- 앱·검사 APK 빌드 성공, 기존 단위 테스트 359개 통과, Lint 오류·경고 0개.
- 기기 검사 **4개 통과**: 신규 화면 검사 2개 + 기존 이용 흐름 검사 2개.
- 화면 검사: 1,618dp / 글자 배율 1.2, 780dp / 1.2, 480dp / 2.0에서 터치 영역, 카드 겹침, 텍스트 잘림, 메뉴 연결 확인. 기본 화면의 주요 기능이 한 화면 높이에 들어오는 것도 확인했다.
- 실제 이용 흐름: 날씨 교육·차량 기능·코스·준비 확인·주행·복습·주차 및 중단 후 준비 확인·복귀 통과. 검사 후 기존 사용자 설정과 기록을 복원했다.
- 최종 화면을 직접 캡처해 기본 해상도에서 모든 주요 카드가 보이고 글자·카드가 겹치지 않는 것을 확인했다. 출발 준비와 차량 상태 바로가기를 직접 누르고 정상 화면 이동을 확인한 뒤 준비와 연습 화면을 열어 두었다.

# 함께하는 연수 — 글레오 대화 연결

2026-11-12 · 차근 v0.10.0 · Pleos Connect 2.1 에뮬레이터

## 사용 흐름

1. **함께하는 연수 → 글레오와 연수 대화**를 연다. 앱 밖에서도 글레오에게 차근의 운전 조언을 요청할 수 있다.
2. 먼저 ‘글레오’라고 부르고 응답 뒤 “차근 연수 대화 시작해 줘”라고 말한다. 화면의 **차근에 요청이 도착했어요** 표시로 실제 연결을 구분한다.
3. 궁금한 주제를 말하고 “방금 내용을 순서대로 더 자세히 설명해 줘”처럼 이어서 질문한다. 글레오의 듣기가 끝났으면 ‘글레오’라고 다시 부른다.
4. “차근 연수 대화 종료”라고 말하거나 **연수 대화 마치기**를 누른다.

현재는 실제 차량이 **P·정차 상태이며 플랫폼이 화면 사용을 허용할 때의 연수**다. 주행 중 상시 코칭으로 확장한 것은 아니다.

## 프로토타입 범위와 소개서 작성 메모

2026-11-12 사용자 결정: **주행 중 글레오를 불러 차근의 운전 조언을 받는 기능은 미구현으로 유지하며, 본선 진출 후 개발을 검토한다.** 현재 프로토타입에는 P·정차 상태의 연수 대화만 포함한다. 이 결정에 따라 주행 중 실행 조건을 변경하거나 추가 구현하지 않는다.

소개서에는 현재 구현 범위와 향후 계획을 다음처럼 구분해 설명한다.

> 차근 프로토타입은 정차 상태에서 글레오와 대화하며 운전 요령을 배우고 후속 질문을 이어갈 수 있습니다. 본선 진출 시에는 플랫폼의 주행 중 사용 조건을 확인하고, 화면 조작 없이 사용자의 질문에 짧은 운전 조언을 제공하는 음성 기능으로 확장할 계획입니다.

위 확장 계획은 사용자 요청에 답하는 음성 대화다. 주변 차량·도로 상황을 감지해 먼저 안내하는 자동 코칭이나 실시간 진입 판단까지 구현됐다는 의미로 소개하지 않는다. 해당 기능은 점검표 R26에 연결하되 현재 구현 성과와 분리한다.

## 구현 내용

| 항목 | 동작 |
|---|---|
| 자연어 연결 | 글레오가 질문의 주제·의도를 해석하고 차근의 학습 요점을 받아 최종 음성 답변을 만든다. 차근이 글레오의 자유 대화 API를 직접 호출하는 방식은 아니다. |
| 질문 범위 | 차로 변경, 미러·사각지대, 회전 준비, 출발·정지, 주차 준비, 빗길, 야간 운전 |
| 후속 질문 | 현재 주제, 직전 질문과 안내를 임시로 유지해 이유·단계·주의점·짧은 설명 요청을 처리한다. 진행 중인 연수는 다음 질문을 요청하는 `asking` 응답을 반환하고, 명시적으로 종료하면 `success`로 마친다. 주제가 없거나 범위 밖이면 다시 질문한다. |
| 차량 정보 | 동의한 실제 차량 입력 중 신선한 속도·기어만 응답 문맥에 포함한다. 시험용 차량 값, 오래된 값, 동의 없는 값은 실제 신호로 제공하지 않는다. |
| 음성 충돌 | 글레오 대화 화면 진입 시 차근의 기존 STT·TTS와 가상 조작 안내를 멈춘다. 글레오가 듣기와 답변을 담당한다. |
| 대화 종료 | 종료 요청·버튼·연수 메뉴로 돌아가기에서 차근의 임시 대화를 비운다. 10분 지난 문맥은 다음 요청에서 만료 처리한다. |
| 화면과 저장 | 큰 글씨로 최근 질문과 학습 요점을 표시한다. 최근 6개 질문을 메모리에만 유지하며 파일로 저장하지 않는다. 화면의 요점과 글레오가 실제 말한 문장은 다를 수 있다. |

글레오 자체의 대화 기록·보관 정책은 차근의 임시 메모리와 별개다. 차근은 사용자의 전체 기록·체격·좌표를 이 대화 응답에 넣지 않는다.

주변 교통이나 장애물은 관측하지 않으며 진입 허가·실제 주차 거리·핸들 회전 수를 판단하지 않는다. 현재 예보를 묻는 요청은 기존 날씨 조회로, 주차 연습 실행은 기존 가상 연습으로 연결된다.

## 공개 규격에 맞춘 기능 구성

Gleo Interface는 앱당 최대 세 function을 등록한다. 이번에는 다음 세 개를 공개한다.

- `TALK_WITH_DRIVING_COACH`: 연수 질문·후속 설명·종료 및 출발 준비 확인(`PREPARATION`)
- `GET_WEATHER_DRIVING_ADVICE`: 현재 예보에 따른 조언
- `START_PARKING_PRACTICE`: 가상 주차 연습 시작

기존 `CHECK_DEPARTURE_READINESS` Intent 수신은 호환성을 위해 유지한다. 패키지명이 붙은 실제 글레오 호출과 공식 예시의 짧은 호출명을 모두 받는다. OpenAI API 키와 중계 서버는 필요하지 않다.

## 검증

| 검사 | 결과 |
|---|---|
| 빌드·단위 검사·lint | 격리 빌드 성공. 단위 검사 379개 통과, lint 지적 0개. |
| 실제 앱 Intent·후속 질문·STT 중지 | 에뮬레이터 계측 검사 6개 통과. 연수 주제·후속 설명·종료·기존 기능·동의 흐름을 검사했다. 마지막 `asking` 보완 뒤에는 연수 대화 계측 검사를 다시 실행해 1개 통과했다. |
| 합성 음성 주입 | 공식 에뮬레이터 gRPC의 오디오 주입 단계에서 프로세스가 종료되어 중단했다. 데이터를 유지해 재시작하고 PC 마이크 전달을 복구했다. 이 검사는 음성 연동 성공 근거로 사용하지 않는다. |
| 사용자 실제 발화 1차 | 일반 질문에 답변은 나왔지만 `cloud_call_vehicle_manual_agent`로 분류됐고 차근 요청 수신은 없었다. 글레오 자체 차량 설명서 답변이며 차근 연결 성공으로 표시하지 않았다. |
| 사용자 실제 발화 2차 | 사용자가 **차근 요청 도착 표시와 연수 답변이 나옴**을 확인했다. 실제 로그에서도 `START` → 차근 `asking` → `ASK`(`question=차로 변경`, `topic=LANE_CHANGE`) → 차근 응답을 확인했다. |
| 답변 후 추가 질문 | **최종 버전에서 확인 완료.** 사용자가 “차로 변경” 답변 뒤 “순서대로 좀 더 자세히 알려줘”라고 이어 말했고, 새 질문과 단계별 답변이 추가됐다고 확인했다. 로그에서도 `ASK`, `topic=LANE_CHANGE`, `focus=STEPS`와 차근의 `asking` 응답을 확인했다. 화면 캡처에서 두 질문과 각 학습 요점이 표시되는 것도 확인했다. |
| 연속 듣기 설정 | 에뮬레이터의 **차량 설정 → Gleo AI → 연속 대화**를 켰고 스위치 값 `true` 및 PC 마이크 전달 `true`를 확인했다. 최종 연수 응답 후 글레오가 다시 듣기에 들어갔다. 아무 말 없이 약 5초 지나면 듣기가 종료되는 플랫폼 동작은 유지되며, 이때는 ‘글레오’라고 다시 부르면 된다. |

빌드 근거: `.tooling/gleo-conversation-build.log`. 계측 근거: `.tooling/gleo-conversation-device.log`의 `OK (6 tests)` 및 마지막 연수 검사 재실행 `OK (1 test)`. 실제 마이크 후속 질문 근거: `.tooling/gleo-conversation-voice-final.log`, 화면: `.tooling/gleo-conversation-final-verified.png`. 종료·문맥 삭제는 계측 검사로 확인했으며 이번 사용자 마이크 확인 범위는 시작·주제 질문·후속 단계 설명이다. 합성 음성을 PC 스피커로 재생한 마지막 시도는 발화 인식 없이 종료되어 성공 근거에 포함하지 않았다. gRPC 합성 주입을 반복하거나 시스템 앱의 비공개 호출 경로를 사용하지 않았다.

# 성장형 운전 튜터 콘텐츠 근거

조사 기준일: 2026-11-08. 이 문서는 정차 중 사용하는 **가상 상황 학습**의 콘텐츠 근거다. 법규, 차량 사용설명서의 조작 안내, 제품의 학습 설계를 구분한다. 실제 도로의 안전한 진행 각도나 차량 제어 권한을 확보했다는 뜻이 아니다.

## 구현에 바로 쓰는 문구

| 주제 | 짧은 안내 문구 | 구분 / 채점 조건 |
|---|---|---|
| 운전 자세 | 시트에 깊숙이 앉고, 브레이크를 끝까지 밟아도 무릎이 조금 굽혀지는지 확인해요. 등과 어깨를 등받이에 둔 채 핸들에 무리 없이 닿아야 해요. | 차종 사용설명서에 따른 출발 전 자기 확인. 키·체격으로 안전한 위치를 자동 확정하지 않음. |
| 핸들 위치 | 안전하게 정차한 상태에서 핸들 위치를 맞추고, 조절 장치가 고정됐는지 확인해요. | 주행 중 높이·거리 조절을 유도하지 않음. 차량별 조작 방식이 다름. |
| 미러 | 자세를 먼저 맞춘 뒤, 실내 미러로 후방 시야를 확인해요. 좌우 미러를 확인해도 사각지대는 남을 수 있어요. | 모든 차에 동일한 미러 각도나 차체 비율을 정답으로 강제하지 않음. |
| 출발 | 안전벨트, 문, 주변과 사각지대를 확인한 뒤 출발을 준비해요. | 학습 체크리스트. 센서가 관찰했다는 표시와 사용자가 확인했다는 표시를 분리. |
| 실선 | 이 구간의 흰색 실선은 진로변경 제한선이에요. 차로를 유지하고, 변경이 허용되는 구간에서 주변을 확인해요. | 백색 진로변경제한선이 명시된 가상 장면. 모든 종류의 실선을 같은 의미로 취급하지 않음. |
| 우회전: 차량 적색 | 정지선 앞에서 완전히 멈춰요. 이후 보행자와 다른 차의 통행, 우회전 전용 신호를 확인해요. | 정지선·횡단보도·교차로 위치를 화면에 명확하게 표현. 멈추기만 하면 자동 진행 허용이라는 뜻이 아님. |
| 우회전: 보행자 | 횡단보도를 건너거나 건너려는 사람이 있어요. 멈추고 안전하게 건널 때까지 기다려요. | 보행자 보호 의무. 보행신호 색만 보고 정답을 결정하지 않음. |
| 우회전: 전용 신호 | 우회전 전용 신호가 있어요. 녹색 화살표 신호에 따라 움직이고 보행자도 계속 살펴요. | 전용 신호 적색에서 보행자가 없다는 이유로 진행하면 안 됨. |
| 고속도로 추월 후 | 추월을 마쳤어요. 오른쪽 차로의 안전거리를 확인하고 방향지시등으로 알린 뒤 주행 차로로 돌아가요. | 승용차, 편도 2차로 고속도로, 정체 없음, 실선 아님이라는 가상 조건을 명시. 일반도로 1차로에 일괄 적용하지 않음. |
| 좁은 골목 교행 | 먼저 멈추고 사람과 뒤쪽 공간을 확인해요. 통과 여유가 불확실하면 무리하게 밀고 들어가지 말고 안전한 공간과 상대 차의 움직임을 확인해요. | 정확한 차량 폭·미러·장애물 위치 없이 ‘이 각도로 가면 안전’이라고 판정하지 않음. |
| 좁은 비탈길 교행 | 이 장면은 비탈진 좁은 도로에서 서로 마주친 상황이에요. 올라가는 차는 우측 가장자리로 양보할 준비를 하고, 실제로 피할 공간이 있는지 먼저 확인해요. | 도로교통법 제20조의 특수 조건. ‘올라가는 차 우선’이라는 일반화는 사용하지 않음. 안전한 공간이 없는데 무조건 움직이거나 후진시키지 않음. |
| 터널 | 오염된 공기 유입을 줄이려면 창문과 공조 상태를 확인해요. 필요한 구간을 지나면 환기 상태도 다시 확인해요. | 쾌적성·차량 기능 안내. 창문을 열었다고 교통법규 위반 점수를 매기지 않음. 터미널 일반 규칙으로 확대하지 않음. |
| 양보와 감사 | 양보해 준 차가 있어요. 먼저 방향지시와 안전거리를 유지해 차로 변경을 마무리해요. 감사 표현보다 차량의 안전한 조작이 먼저예요. | 감사 비상등 ‘두 번’은 확인된 법정 의무가 아님. 사용하지 않았다고 감점하지 않음. 실제 비상등 자동 제어 없음. |

## 확인된 근거와 적용 범위

### 1. 자세·미러·핸들

현대차의 자세 안내는 페달 도달성, 무릎 굽힘, 핸들 도달성, 헤드레스트 위치처럼 실제 몸과 차량 사이의 조건을 확인하도록 한다. 따라서 **키 하나를 넣으면 안전한 시트 좌표가 산출된다**는 기능으로 제시할 수 없다. 프로토타입의 체격 입력은 설명 순서와 도식의 개인화에만 사용하고, 좌석 위치는 운전자가 차종 설명서를 보며 직접 확인하게 한다. 이는 문서에 근거한 제품 설계 판단이며, 의료·인체공학 모델의 검증 결과가 아니다.

- [현대차 DN8 2024: 올바른 운전 자세](https://ownersmanual.hyundai.com/full_webhelp/DN8/2024/ko_KR/id833d0d6e58a.html)
- [현대차 US4 2026: 시트 조작부 명칭과 주행 전 조절](https://ownersmanual.hyundai.com/full_webhelp/US4/2026/ko_KR/safety_system_seat.html)
- [현대차 NH2 2026: 실내 미러](https://ownersmanual.hyundai.com/full_webhelp/NH2/2026/ko_KR/id3bb379f062d.html)
- [현대차 NH2 2026: 디지털 실외 미러](https://ownersmanual.hyundai.com/full_webhelp/NH2/2026/ko_KR/idf947c7fe039.html)

실내 미러는 후방 시야가 보이도록 조정한다. 미러·카메라에 사각지대가 있을 수 있고, 미러 화면은 실제 물체와 거리감이 다를 수 있다. 시뮬레이션의 표시 영역을 실차의 사각지대 전부라고 주장하지 않는다.

또한 현대차 일부 사양에는 신체에 맞는 시트·핸들·HUD·실외 미러 설정을 추천하는 **스마트 자세 제어**가 이미 있다. 따라서 체격 기반 자세 추천 자체를 완전히 새로운 기능이라고 주장하지 않는다. 본 프로토타입의 차별화는 출발 전 학습부터 상황 판단, 복습까지 이어지는 학습 과정이다.

- [현대차: 시트 기능 설정 / 스마트 자세 제어](https://ownersmanual.hyundai.com/docview/webhelp/Hyundai/19da8a75-d5be-43b8-9c69-9f888be5a155/id224QI050M5Z.html)

### 2. 우회전

보행자 보호 기준은 횡단보도를 건너는 사람뿐 아니라 건너려는 사람도 포함한다. 보행신호 녹색 여부만으로 우회전 가능 여부를 결정하는 단일 점수 규칙은 부정확하다. 차량 적색의 선행 정지, 우회전 전용 신호, 보행자, 다른 교통의 흐름을 각각 나눈 장면을 사용한다.

- [도로교통법 제27조 조문정보](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1027503563): 조문정보 표제에 시행 2026-10-13 표시. 해당 보호 의무 문구는 2022-01-11 개정 표기를 포함한다.
- [경찰청: 우회전 신호등은 녹색화살표 신호에만 우회전](https://www.police.go.kr/user/bbs/BD_selectBbs.do?q_bbsCode=1002&q_bbscttSn=20230117143939074): 2023-01-17 발표, 2023-01-22 시행 안내. 본문 페이지는 조회 환경에 따라 리디렉션 오류가 있으나 공식 검색 결과와 제목·첨부 목록을 확인했다.
- [경찰청: 개정 도로교통법 안내](https://www.police.go.kr/user/bbs/BD_selectBbs.do?q_bbsCode=1007&q_bbscttSn=20220407172358422): 차량 적색 일시정지, 보행자 보호의 조건을 설명한다.

주의: 국가법령정보센터의 조문정보에서 ‘전체조문보기’를 열면 시행 예정 버전으로 연결되는 경우가 관찰됐다. 시행 예정 법령을 현행으로 뭉뚱그리지 않고, 이 문서에 기록한 조문·시행일을 기준으로 사용한다. 실제 배포 시 전체 법령의 적용 시점을 다시 확인한다.

### 3. 실선 진로변경과 고속도로 추월차로

백색 실선의 **진로변경제한선**에 관한 문제로 장면을 한정한다. 노면의 모든 실선이 똑같은 의미라는 설명은 하지 않는다. 도로 파손·공사 등 법령상 별도 조건과 경찰관 지시가 있는 상황까지 ‘어떠한 경우에도’라는 말로 일반화하지 않는다.

- [도로교통법 시행규칙 별표 6: 안전표지](https://www.law.go.kr/flDownload.do?bylClsCd=110201&flSeq=146448457): 확인한 파일의 개정 표기는 2024-11-14, 진로변경제한선 항목 506~508.

고속도로의 추월차로는 도로 종류와 차종에 따른 규정이다. 통행량 증가 등 도로 상황 때문에 부득이하게 시속 80km 미만으로 통행할 수밖에 없는 경우에는 예외가 있다. 운전자가 스스로 80km/h 아래로 달린다는 사실만으로 예외를 인정하면 안 된다. 프로토타입의 추월 복귀 장면은 정체가 없는 승용차 상황으로 제한한다.

- [도로교통법 시행규칙 별표 9: 차로에 따른 통행차의 기준](https://law.go.kr/LSW/flDownload.do?bylClsCd=110201&flSeq=150064993): 확인한 파일의 개정 표기는 2022-10-20.
- [경찰청: 고속도로 지정차로제](https://www.police.go.kr/user/bbs/BD_selectBbs.do?q_bbsCode=1007&q_bbscttSn=20230629113112510): 2023-06-29 안내.

### 4. 좁은 도로·비탈길의 교행

도로교통법 제20조 제2항은 좁은 비탈길에서 마주보고 진행하는 상황에서 **올라가는 자동차**가 도로 우측 가장자리로 피하여 양보하도록 규정한다. 비탈길 외의 좁은 도로에서도 동승자·적재 여부에 관한 별도 조건을 둔다. 따라서 단순히 ‘경사가 있으면 내려오는 차가 무조건 양보’하거나 ‘골목에서는 먼저 들어온 차가 항상 우선’이라는 학습 문구를 사용하지 않는다.

- [도로교통법 제20조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0020&lsiSeq=281875&urlMode=lsScJoRltInfoR): 직접 확인한 본문은 시행 2026-07-01 버전이며, 해당 조문은 전문개정 2011-06-08로 표시된다. 이 조항의 이후 개정 여부는 실제 배포 직전 다시 확인한다.

법의 양보 의무와 ‘지금 몇 도 돌려서 어느 위치로 후진할지’는 별개의 문제다. 실제 장면에서 차량 폭·축거·최소 회전반경·노면 경사·도로 끝·사람·후방 교통이 확인되지 않으면 안전 각도를 산출할 수 없다. 가상 장면의 차 이동은 미리 정의된 예시일 뿐 실차의 안전한 경로 보장이 아니다.

### 5. 터널과 감사 비상등

현대차 일부 모델은 터널 접근 시 유리창을 닫고 실내 순환으로 전환하는 외부 공기 차단 기능을 이미 제공한다. 이는 오염 공기 유입 감소 목적의 차량 편의 기능이다. 확인한 근거만으로 ‘모든 터널에서 창문을 닫아야 하는 법적 의무’라고 표시하지 않는다. 사용자의 ‘터미널’은 프로토타입에서 **터널 진입** 상황으로 한정했다.

- [현대차 MX5 2026: 외부 공기 차단 기능](https://ownersmanual.hyundai.com/full_webhelp/MX5/2026/ko_KR/id9b5991bc110.html)

현대차 사용설명서는 비상 경고등을 비상 상황을 알리는 용도로 설명하며, 비상등 작동 동안 방향지시등이 작동하지 않는다고 안내하는 모델도 있다. 불필요한 점등은 다른 운전자에게 혼란을 줄 수 있다. 따라서 끼어드는 동안 앱이 감사 표시로 비상등을 자동 점등하는 기능을 구현하지 않는다. ‘두 번’이라는 감사 표현을 법규 정답이나 의무로 채점하지 않는다.

- [현대차 CE1 2024: 비상 경고등](https://ownersmanual.hyundai.com/full_webhelp/CE1/2024/ko_KR/idd7334e78f90.html)
- [현대차 NH2 2026: 고속도로 주행 보조 작동](https://ownersmanual.hyundai.com/full_webhelp/NH2/2026/ko_KR/idfd78f98c603.html): 비상등 점등이 차로변경 보조 작동 조건·취소와 관련됨. 차종별 시스템에 영향을 줄 수 있다는 추가 근거이며, 모든 차가 같은 방식이라는 뜻은 아니다.

## 점수·순위의 의미

다음은 법령이 정한 점수체계가 아니라 프로토타입의 학습 설계다.

- 점수 이름은 **가상 연습 점수 / 학습 진행도**로 한다. 실차 운전 숙련도·면허·보험 위험 점수와 혼동하지 않도록 한다.
- 정답 선택·관찰 순서·복습을 보상하고, 빠른 통과·무리한 끼어들기·가속·경쟁 속도를 보상하지 않는다.
- 같은 문제 반복으로 무한 점수를 만들기보다 해당 과제의 최고 학습 결과와 개선을 기록한다.
- 순위에 가상 참가자를 표시한다면 **데모 순위**를 명시한다. 실제 사용자나 다른 차의 주행 데이터를 수집했다는 인상을 주지 않는다.

# 현대 기획자료 대비 차근 앱 기능 재점검

점검일: **2026-11-12, 한국 시간**

기준: [현대 기획자료.pdf](<C:/Users/user/Documents/카카오톡 받은 파일/현대 기획자료.pdf>) **2쪽 전체**

대상: `main`의 `345a634`와 점검 시점의 로컬 변경 사항. 아반떼 CN7 가솔린 1.6, 자동 날씨 안내, 도로 교육, 사용자 문구 정리, 새 준비와 연습 화면을 포함한다.

**현재 앱은 출발 준비·실제 날씨 조회·차량 기능 교육·가상 운전 및 주차 연습을 제공한다. 실제 도로를 이용하는 AI 연수 코스, 주행 중 상시 코칭, 후·측방 센서를 이용한 주차 도움까지 완성된 상태는 아니다.**

최초 작성은 원문 재변환·전 페이지 시각 대조·현재 코드 확인·기존 검사 로그 재확인으로 진행한 읽기 전용 점검이었다. 이후 같은 날 사용자 요청에 따라 프로토타입 코드를 보완하고 에뮬레이터 검사를 새로 실행했다. 아래 내용은 후속 구현을 반영하며, 최초 검사 기록과 새 검증의 범위는 구분한다. 상세 변경·실행 근거·미확인 사항은 [프로토타입 보완 결과](PROTOTYPE_IMPROVEMENTS_2026-11-12.md)를 참고한다.

### 이전 판정과 달라진 점

- 이전 점검표는 R03 ‘날씨별 음성’을 부분 구현으로 표시하면서 시동 연동·백그라운드 동작의 부재도 그 이유에 포함했다. 이번에는 **상황별 조언 생성과 자동 읽기는 구현**, 시동 연동은 **R01**, 백그라운드 코칭은 **R26**으로 구분한다. 같은 누락을 중복 집계하지 않기 위한 판정 정리이며, 이 문서 작업에서 새 기능을 구현한 것은 아니다.
- 따라서 이전 **6 / 17 / 5**에서 이번 **7 / 16 / 5**로 집계가 달라졌다. TTS의 간헐적 깨짐이 해결됐다는 뜻은 아니다.
- 사용자가 나중에 승인한 **‘시동 때 자동 실행이 어렵다면 차근을 열었을 때 날씨를 알려주기’는 구현되어 있다.** 원문과 비교하기 위해 R01은 미구현으로 남기지만, 현재 합의한 대체 동작을 빠진 기능으로 취급하지 않는다.
- 시트·미러는 원문에서 **음성 안내**를 요구했다. 실제 시트 자동 이동을 원문 필수 요구로 추가하지 않았다.
- ‘이중 주차’는 사용자의 설명에 따라 **다른 차 앞을 가로막아 세우는 상황**으로 해석했다. 평행 주차나 일반 후진 주차와 구분했다.

### 추가 계획과 별도로 관리할 사항

- **현재 기능의 후속 보완:** 설명서 2개 항목, 이중 주차 시각 교육, D10·D11·D13 각각 2개 가상 상황을 추가했다. 음성 중복 요청과 종료 처리 결함을 수정했다. 간헐적인 음질 깨짐은 원인 미확정으로 유지하며, 교육의 보완을 실도로·실센서 구현 완료로 집계하지 않는다.
- **기본 내비 오류:** 흰 지도·위치 문제는 새 기능이 아니라 기존 연동의 미해결 문제다. 해결 완료로 표시하지 않는다.
- **시동 자동 실행:** 현재 합의한 대안인 ‘차근 실행 시 날씨 자동 안내’를 유지한다. 시동 연동을 본선의 필수 추가 기능으로 다시 지정하지 않는다.
- **시트·미러 자동 조절, 자율주행:** 현재 성과나 확정된 본선 개발 목록에 포함하지 않는다.

소개서 문구 초안:

> 차근은 초보 운전자가 출발 전 준비를 확인하고, 현재 날씨에 맞는 조언을 들으며, 글레오와의 정차 중 대화와 가상 주행·주차 연습으로 운전 요령을 익히는 프로토타입입니다. 본선 진출 시에는 플랫폼의 허용 조건을 확인해 주행 중 요청형 음성 대화로 확장할 계획입니다. 실제 도로 기반 맞춤 연수 코스와 데이터 기반 상황별 코칭은 연동 환경을 확보한 뒤 단계적으로 검토합니다.

## 7. 검증 근거와 확인하지 않은 범위

### 이번 문서 작업에서 직접 확인한 것

1. 원본을 전용 MarkItDown으로 다시 UTF-8 Markdown 변환했다. 새 변환 결과의 SHA-256이 기존 무편집 변환본과 같다.
2. PDF를 로컬에서 렌더링하여 **1쪽·2쪽 전체를 시각 확인**했다. 회색 상자의 주행 교육·개선 방향, 페이지를 넘어 이어지는 5번 항목, 주차의 센서→LLM 관계, 시동→날씨→안내 순서까지 대조했다.
3. 제목·항목·수치·메모의 텍스트 누락은 발견하지 못했다. 폰트 `FontBBox` 경고가 있었지만 변환 내용과 원문 화면을 대조했다. 별도 이미지·도표·OCR 추가가 필요한 부분은 없었다.
4. ‘촬영 수요일 3시’, ‘숏폼: 시연 영상’, ‘날씨 얘기 나오고, 기능 얘기’는 모두 확인했다. 제작 메모이므로 구현 기능 수에 넣거나 실행 지시로 취급하지 않았다.
5. 아래 코드의 실제 메뉴 연결, 데이터 제공자, 상태 처리, 차량 신호 수신 범위를 확인했다. 이름만 존재하는 AI·거리 인터페이스를 완성 기능으로 계산하지 않았다.

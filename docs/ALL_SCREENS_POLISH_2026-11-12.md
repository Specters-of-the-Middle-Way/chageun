# 전체 화면 스타일·가독성 점검 — 2026-11-12

현재 차근 앱의 일반 메뉴에서 열 수 있는 화면을 기준으로 확인했다. 먼저 정리한 준비·연습·교육 화면의 스타일을 유지하면서 차량 상태, 날씨 예시, 정차 교육, 재방문, 함께하는 연수와 팝업까지 같은 스타일로 맞췄다.

## 공통 변경

- 배경은 밝은 회색, 내용은 흰색 카드, 선택·주요 동작은 짙은 녹색, 요약·안내는 연한 녹색으로 통일했다. 스위치·입력 강조색도 맞췄다.
- 새로 정리한 화면의 본문은 주로 21~24sp, 버튼은 20sp 이상으로 표시한다. 기존 작은 보조 글씨는 최소 18sp로 올렸다. 앱의 글씨 확대 설정을 함께 적용한다.
- 주요 버튼의 최소 높이는 64dp이며 긴 문구는 줄바꿈한다. 비활성 버튼은 회색 배경과 읽을 수 있는 진한 회색 글자로 구별한다.
- 화면 캡처에서 발견한 선택 버튼의 회색 배경 문제도 수정했다. 버튼이 배경을 복제할 때 실제 배경에 선택·활성 상태를 다시 전달하며, 일시정지 시 버튼 전체를 흐리게 하던 처리를 제거했다. 실제로 그려진 색상을 비교하는 회귀 검사를 추가했다.
- 팝업 제목은 26sp, 본문은 22sp, 선택 목록·버튼은 최소 20sp로 맞췄다. 네이티브 팝업의 확인·취소·동의 동작은 유지한다.
- 긴 본문은 스크롤하고 다음 행동은 하단에 유지한다. 연수 화면의 중복 스크롤을 제거하고 주제 제목·시작·일시정지·마무리·복습 종료 버튼을 고정했다.
- 재방문·정차 교육·날씨 예시·가상 연습 기록에도 같은 카드와 제목 구성을 적용했다. 운전자 설정의 왼쪽 메뉴는 글씨가 커져도 스크롤할 수 있다.
- 글레오 연수의 자체 글씨 확대가 앱 확대와 중복되던 부분을 정리했다. 안내 내용과 버튼 크기는 공통 기준에 맞췄다.

## 검증 환경과 결과

- Pleos 에뮬레이터 `emulator-5554`, Android 사용자 10, 실제 앱 `kr.drivestep.tutor`에 최신 APK를 설치했다.
- 실제 화면 크기 2560×1440에서 확인하고, 앱 영역 1707×1018dp의 글씨 배율 1.2·1.6과 1100×650dp의 좁은 창에서도 배치를 검사했다.
- 빌드 성공. 단위 검사 **379개 통과**, 실패·오류·건너뜀 0개. Android Lint **오류·경고 0개**.
- 기기 검사 **36종 통과**: 추가 화면의 배치·실제 메뉴 이동·차량 조작·버튼 색상 5종과 기존 화면·기능 회귀 31종이다. 마지막 버튼 상태 수정 후에는 추가 화면 5종과 준비·주행·주차 8종, 총 **13종을 최종 APK에서 다시 통과**했다.
- 새로 정리한 화면 39개 캡처와 기존 연습·교육·날씨의 대표 캡처를 보고 카드 정렬, 잘림, 비활성 버튼, 팝업을 확인했다. 계측 검사에서는 전체 단계·상황의 글자 잘림과 버튼 배치도 확인했다.
- 실제 날씨 조회는 11월 12일 17:30 예보 기준 **12.7°C·구름**으로 표시됐다. 조회 취소·재조회·동의 해제·자동 조회 검사도 통과했다.

## 확인 범위

- ‘전체 화면’은 차근 앱의 현재 일반 메뉴와 앱이 표시하는 팝업을 뜻한다. 에뮬레이터 시스템 런처·기본 내비·왼쪽 3D 차량은 앱의 화면이 아니므로 이 변경에 포함하지 않는다.
- 소스에 남아 있지만 현재 메뉴에 연결되지 않은 이전 성장 코치·상황 코치·주행 코치·옛 주차 교육 컴포넌트는 작은 글씨와 버튼 높이를 코드에서 점검했다. 이 숨겨진 경로의 실제 실행을 검증했다고 표시하지 않는다.
- 목적지는 입력 검증과 전송 확인창의 취소까지 검사했다. 이번 UI 점검에서는 내비로 목적지를 전송하지 않았다. 기본 내비의 흰 지도 문제를 해결한 변경도 아니다.
- 연수에서는 글 입력과 가상 조작, 대화 연결·중지·복습을 확인했다. 원격 글레오 음성 인식·응답 품질이나 TTS 음질을 새로 검증한 결과는 아니다.
- 방향지시등·조향은 연결된 신호를 받아 진행 화면을 열고 직접 종료하여 복습 화면까지 확인했다. 이번 UI 검사에서 실제 차량 장치를 움직이거나 조작 순서 전체를 완료한 것은 아니다.
- 기존 사용자 기록을 보존하고 검사에서 바꾼 앱 설정을 복원했다. 연수의 임시 기록은 저장 동의를 끈 상태에서 검사했다. 차량 조작 화면 검사에 필요한 임시 기록만 생성·정리했다.
- 기능의 기획 대비 구현 등급은 UI 변경으로 올리지 않는다. 실제 시트 이동·주변 차량 감지·실제 경로 주행 등 기존 미구현 범위는 그대로다.

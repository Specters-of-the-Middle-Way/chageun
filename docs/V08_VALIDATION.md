# v0.8 검증 기록

검증일: 2026-11-09. 환경: Pleos 2.1.0 / Android 14, emulator-5554, 현재 차량 사용자, 1920×1080 화면의 앱 영역 약 1255×850. 실차 검증 결과가 아닙니다.

## 빌드·모델

- Debug APK 및 Release unsigned APK 빌드.
- 전체 JVM 단위 테스트 **205개 통과**: 기존 148개 + 주차 모델 33개 + 준비 흐름 24개.
- Android lint: **오류 0, 경고 30**. 기존 권한·지원 라이브러리·문구 리소스화 등의 경고가 남아 있습니다.
- 주차 두 코스 모두 기어·페달·조향 입력으로 가상 목표에 도달하는 경로를 테스트했습니다. 목표 위치로 강제로 이동시키는 방식은 사용하지 않았습니다.
- 좌표·충돌·구역 네 모서리·방향 허용치·정지/브레이크 기어 조건·일시정지·완료 후 상태 고정과 잘못된 입력을 확인했습니다.
- 준비 상태는 미확인 항목을 완료로 처리하지 않고, 시트·핸들 변경 시 미러 확인을 해제합니다. 재방문은 출발 전 7개 항목을 초기화합니다.

빌드 출력은 로컬 동기화 폴더의 생성 파일 중복을 피하려고 `/private/tmp/drivestep-v08-build`를 사용했습니다. 배포 APK는 프로젝트의 일반 `app/build/outputs/apk/` 위치로 복사합니다.

## 에뮬레이터 화면 검증

`python3 -u scripts/verify-v08.py`는 다음을 화면 조작으로 확인합니다. 각 항목의 최종 실행 결과는 아래 실행 결과에 기록합니다.

1. 프로필 → 운전 환경 9개 확인 → 이번 출발 7개 확인 → 연습 선택.
2. 후진 주차: 브레이크 없이 R 선택 시 수정 음성 → 올바른 R 선택 → 직접 후진 → 정지·P·수동 완료 → 자기평가·저장.
3. 평행 주차: 반대 방향의 두 조향 구간을 직접 후진 → 가상 구역·방향 확인 → P·수동 완료 → 저장.
4. 기록 삭제 확인 창에서 취소하면 기존 기록 유지.
5. 일시정지·외부 앱 전환 시 움직임과 음성 중단. 복귀하면 출발 확인을 다시 거친 뒤 명시적으로 재개.
6. 실제 에뮬레이터 기어 D에서는 가상 조작 불가, P로 복귀한 뒤 재개.
7. 저장 동의를 끈 연습은 기존 주차 저장 기록을 변경하지 않음.
8. 모든 가상 조작 동안 실제 에뮬레이터 차량 기어·속도를 변경하지 않음.

`python3 -u scripts/verify-simulator.py`는 기존 운전자 시점의 좌·우 차로 변경, 사각지대 차량 기다림, 음성 수정·완료, 급가속 안내, 중단/재개 및 기록 유지 검사를 새 준비 흐름으로 실행합니다.

## 실행 결과

- 주차·준비 흐름의 위 8개 항목을 에뮬레이터에서 확인했습니다. 후진과 평행 주차는 실제 UI 조작 및 음성 재생 로그, 저장된 `source=SIMULATION` 기록으로 확인했습니다.
- 재방문 시 확인 초기화와 D 상태 조작 차단, 기록 비동의 시 기존 저장 기록 불변을 확인했습니다.
- 자동 검사에서 동일한 `park_exit` 키를 연속 사용한 화면 전환과 이미 체크한 항목의 재선택 때문에 대기가 실패했습니다. 화면별 대기 조건과 체크 상태 판독을 수정하고 해당 구간부터 나머지 검사를 재개해 완료했습니다. 이 실행은 단일 무중단 자동 검사 통과와 구분합니다.
- 기록 삭제는 확인 창과 취소 시 보존을 UI로 검증했습니다. 기존 사용자 기록을 삭제하는 실행은 하지 않았습니다.
- 원본 로컬 로그: `.tooling/build-v08-final.log`, `.tooling/verify-v08-final.log`, `.tooling/verify-v08-resumed.log`.
- `scripts/verify-simulator.py` 전체 통과: 좌·우 차로 변경, 주변 차량 기다림, 잘못된 신호 교정, 급가속 안내, 외부 앱 복귀와 실제 D 제한, 재시작 후 기록 유지. 로그: `.tooling/simulator-v08-regression.log`.
- 최종 시각 검토에서 주행 화면 안내 배지의 배경 대비와 프로필의 안내 선호 표기를 보완했습니다. 변경 후 Debug/Release 재빌드와 lint를 수행했습니다.

## 해석 범위

앱은 실차의 주차 센서·카메라·시트 액추에이터에 연결하지 않습니다. IONIQ 3의 공개 차체 크기를 사용하지만, 조향·페달·충돌 모델의 가정이 포함된 교육용 시뮬레이션입니다. 에뮬레이터의 왼쪽 시스템 패널 차량 그래픽은 기본 이미지이며 IONIQ 3 실차 UI를 재현한 것이 아닙니다. 실제 시트 좌표 산출, 차량별 조향 보정, 운전 능력 향상, 실제 주행 중 코칭은 별도 검증이 필요합니다.

# 차로 변경·주차 연습 화면 정리

작업일: 2026-11-12 · 대상: 차근 / Pleos 2.1 에뮬레이터

## 변경 내용

| 화면 | 변경 |
|---|---|
| 차로 변경 코스 선택 | 운전석 미리보기와 상황 선택을 나란히 배치했다. 왼쪽·오른쪽·옆 차 기다리기를 설명이 있는 큰 카드로 구분하고 시작 버튼을 아래에 고정했다. |
| 차로 변경 연습 중 | 현재 단계와 정지·재개 버튼을 위에, 도로 장면과 안내를 가운데에 두었다. 방향지시등·미러 확인·핸들·페달을 각각 카드로 구분했다. |
| 주차 코스 선택 | 미리보기와 후진·평행·T자·전면 주차 선택, 코스 설명을 카드로 정리했다. 선택한 코스의 시작 버튼을 아래에 고정했다. |
| 주차 연습 중 | 주차 장면 옆에 단계·기어·브레이크 유지·속도·목표 구역 상태를 배치했다. 안내, 핸들, 페달은 별도 카드로 구분했다. |
| 두 연습의 돌아보기 | 결과 요약과 조작 기록, 재시작·코스 선택을 같은 스타일로 정리했다. 주차의 소감 선택과 저장 동의 흐름도 유지했다. |

운전자 설정·준비 화면과 같은 녹색 강조색과 흰색 카드를 사용한다. 주요 제목은 24~32sp, 안내는 21~23sp, 보조 설명은 18~20sp, 기본 조작 버튼은 20sp로 조정했다. 앱의 기존 글자 배율도 적용한다. 버튼은 최소 64dp 높이를 확보하고, 설명은 높이를 고정하거나 말줄임하지 않고 줄바꿈한다.

좁은 창에서는 좌우 카드를 세로로 배치한다. 연습 장면과 조작 영역은 스크롤 안에 두어 높이가 낮은 창에서도 접근할 수 있다. 도로의 미러·속도·정지 표시와 주차장의 제목·목표·경고 문구도 키웠다.

## 동작 범위

- 가상 주행·주차의 물리 모델, 완료 조건, 준비 확인과 정차 조건은 변경하지 않았다.
- 페달의 누름·해제, 핸들 중앙, 방향지시등·미러 확인, 기어 변경 전 정지·브레이크 조건을 유지한다.
- 일시정지·화면 비활성화 시 조작을 해제하고, 이어하기를 명시적으로 눌러야 재개한다.
- 기록 동의가 꺼져 있으면 기기에 연습 기록을 저장하지 않는다. 기존 기록 삭제 범위도 그대로다.
- 버튼 선택 상태가 달라질 때만 배경 스타일을 갱신하도록 해 연습 화면의 반복 갱신에서 불필요한 배경 생성을 줄였다.

## 빌드 및 계측 검사

- `assembleDebug`, `testDebugUnitTest`, `lintDebug`, `assembleDebugAndroidTest` 통과.
- 현재 체크아웃의 JVM 단위 검사 **379개 통과**, Lint **오류·경고 0개**.
- `SimulationScreensDeviceTest` **2개 통과**. 실제 Android 레이아웃 측정과 화면 버튼 콜백으로 다음 항목을 확인했다.
  - 차로 변경 3개 상황, 주차 4개 방식의 선택·시작·일시정지·재개·돌아보기·다시 연습.
  - 방향지시등·미러 선택 상태와 주차 기어 변경, 비활성화 후 자동 재개 방지.
  - 기록 비동의 시 저장하지 않는 동작. 테스트는 별도 임시 저장소를 사용하고 종료 후 정리한다.
  - 1,707×1,018dp / 글자 배율 1.2와 1.6, 1,100×650dp / 배율 1.2에서 텍스트 잘림·말줄임과 터치 크기.

## 실제 앱 화면·조작 검사

Pleos 2.1의 `emulator-5554`, Android 사용자 10에서 `SimulationVisibleFlowTest`로 실제 `MainActivity`의 버튼과 터치 이벤트를 실행했다. 가상 차량의 위치나 완료 상태를 강제로 주입하지 않았다.

| 확인 항목 | 결과 |
|---|---|
| 왼쪽·오른쪽 차로 변경 | 방향지시등 → 미러 → 조향 → 핸들 중앙 → 신호 끄기 → 완료 화면 확인 |
| 옆 차 기다리기 | 옆 차가 지나가는 단계 뒤 같은 조작으로 완료 화면 확인 |
| 주차 4개 코스 | 코스 선택 시 미리보기·설명·시작 버튼이 해당 코스로 바뀌는 화면 확인 |
| 후진 주차 전체 과정 | 브레이크 → R → 가속 → 목표 구역 진입 → 제동 → P → 주차 마침 → 소감 선택·저장 없이 마침 확인 |
| 일시정지·이어하기 | 두 연습의 정지 표시와 조작 비활성화, 명시적인 재개 확인 |
| 기록 저장 | 검사 중 저장 동의를 끄고, 종료 후 기존 기록 문자열이 그대로인지 확인. 변경한 동의·음성 설정은 원래 값으로 복원 |

실제 캡처에서 코스 선택·연습·돌아보기의 글씨와 배치, 모든 주요 조작부가 기본 창 안에 보이는 것을 확인했다. 보조 버튼이 처음 표시될 때 Android 기본 회색 배경이 남던 문제도 수정했다. 흰색 테두리 버튼과 녹색 선택 버튼이 처음부터 적용된다. APK 내부 코드를 대조하면서 이전 코드가 남아 있는 것을 확인했고, 공유 출력 폴더의 동시 쓰기 충돌도 확인했다. 최종 검증 빌드는 별도 출력·캐시 폴더에서 전체 재빌드했다. 보조 버튼의 둥근 흰색 배경도 기기 검사 항목에 포함했다.

화면 계측 2개와 실제 완료 흐름 1개를 합쳐 **기기 검사 3개 통과**. 평행·T자·전면 주차는 이번 작업에서 각 코스의 화면·버튼·전환을 확인했으며 실제 시간 진행으로 마지막 정렬까지 운전한 코스는 후진 주차다. 이번 변경은 화면 구성·가독성 개선으로, 기획 대비 기능 구현 등급은 변경하지 않는다.

# 가상 코스 화면 정리

작업일: 2026-11-12 · 대상: 준비와 연습 → 가상 코스 · Pleos Connect 2.1 에뮬레이터

## 변경 내용

| 항목 | 반영 내용 |
|---|---|
| 목표와 조건 | 연습 목표, 가상 출발지·제외 조건, 코스 선택의 세 단계로 구분했다. 현재 선택을 녹색으로 표시한다. |
| 코스 후보 | 코스 이름, 과제 수, 설정 거리·시간, 연습 순서를 흰색 카드에 모았다. 선택한 코스는 연한 녹색 카드와 체크 표시로 구분한다. |
| 시작 동작 | 선택한 코스 요약과 시작 버튼을 화면 아래에 고정했다. 선택 전·재조회 후·후보가 없을 때에는 시작 버튼이 비활성화된다. |
| 과제 보완 | 직접 고른 과제와 저장 기록의 추천을 같은 카드에서 확인한다. 다른 코스를 선택해도 사용자가 고른 보완 과제를 덮어쓰지 않는다. |
| 진행과 완료 | 연습 중 현재 과제 순서를 표시한다. 취소한 과제는 다시 연습하며, 마지막 과제를 완료하면 ‘코스 마치고 목록으로’ 이동한다. |
| 가독성 | 제목 24~30sp, 본문·조작부 20~22sp, 보조 설명 18~19sp, 버튼 최소 높이 64dp. 좁은 창에서는 카드가 세로로 배치되고 본문을 스크롤할 수 있다. |

주행 연습·차로 변경·주차 화면과 같은 공통 카드·버튼 스타일을 사용한다. 가상 거리·시간을 실제 내비 경로로 표시하지 않으며, 기존 준비 확인·정차 조건·기록 동의와 각 과제의 완료 조건을 유지한다.

## 검증 결과

| 검사 | 결과 |
|---|---|
| 빌드 | `assembleDebug`, `testDebugUnitTest`, `lintDebug`, `assembleDebugAndroidTest` 통과 |
| 단위 테스트 | 379개 통과, 실패·오류·건너뜀 0개 |
| Android Lint | 오류·경고 0개 |
| 시나리오 QA | JSON 시나리오 5개, 차량 연결 시간 제한, 자세 안내, 음성 에셋 194개, 용어 검사 통과 |
| 코스 화면 계측 2개 | 목표 3종, 후보 3종, 출발지 선택, 왕복 제외·빈 결과, 코스 선택·재조회, 준비 미완료 차단, 취소 후 같은 과제 재시도, 기록 비동의 표시 확인 |
| 가독성·고정 버튼 | 1,707×1,018dp / 글자 배율 1.2·1.6, 1,100×650dp / 배율 1.2에서 텍스트 잘림·말줄임 없음, 터치 영역과 고정 시작 버튼의 화면 내 배치 확인 |
| 실제 완료 계측 1개 | 실제 MainActivity의 버튼·페달·핸들 조작으로 기초 코스의 직진·차로 유지 → 가속·감속·재출발 → 우회전·횡단보도를 완료하고 목록으로 복귀 |
| 회귀 검사 2개 | 앱 전경 복귀 시 출발 준비 재확인·명시적 재개, 저장한 어려움에 따른 코스 추천·기록 동의 해제 처리 확인 |

최종 기기 검사 **5개 통과**. 실제 완료 검사에서는 차량 위치나 완료 상태를 강제로 주입하지 않았다. 왕복 코스 전체를 끝까지 운전한 것은 아니며, 세 과제를 연속 완료한 범위는 기초 코스다. 검사 후 프로필·동의·음성 설정·중단 지점을 복원했고 기존 연습 기록의 불변을 확인했다. 마이크 전달과 글레오 연속 대화 설정은 변경하지 않았다.
